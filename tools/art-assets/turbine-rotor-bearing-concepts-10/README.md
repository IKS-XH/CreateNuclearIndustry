# 汽轮机转子与轴承设计稿 10A

本目录保存三种转子/轴承外观的离线方案。打开 `index.html` 可选择A/B/C、3/5/7尺寸、端面/三分之四/观察窗视图、拆件和演示转速。动画仅为设计稿演示，不代表游戏已有转速同步或客户端动画。

六张16×16 SVG是新表面纹理来源；`geometry.json`保存样稿几何比例；`preview.js`以闭合多边形投影到页面。机壳图只读引用当前R2素材。此批不生成PNG、不安装游戏资源、不改生产模型或代码。

使用本目录的 `check_concepts.py` 做有限源图、几何边界和预览引用检查。负责人浏览器复看及阶段结论记录在 `docs/art/reports/ART-TURBINE-10A-CONCEPTS.md`。
