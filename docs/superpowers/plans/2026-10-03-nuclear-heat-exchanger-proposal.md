# 首台核换热器：接通Create原生锅炉

**状态：推荐方案，等待用户确认新增范围与参数；尚未派发功能实现。** 用户要求在材料、设备与反应堆制造验收后继续主线。本方案遵循无GUI和谨慎使用序列装配的新规则，先让现有反应堆热液形成一条真实可用的发电支线。

## 1. 本批结果与后续分界

```text
反应堆热端 → Create管道/泵 → 核换热器 → 冷冷却剂 → 反应堆冷端
                                  ↓ 向上供热
                           Create储罐锅炉＋蒸汽引擎 → 旋转动力
```

推荐首批只实现现有`nuclear_heat_exchanger`身份的核热模式，直接给顶部Create储罐锅炉供热。不新建专用锅炉/汽轮机，不注册普通/超临界蒸汽；三模式最终规划保留，蒸汽供热和冷凝随后接入。

工作盆供热另批。源码核查发现Create在匹配盆配方时先检查热级，不能用“当前匹配到了配方”来触发预热，否则互相等待；要满足“有效配方才耗液”，需要独立、忽略热条件的输入/输出可行性判定。本批避免先用“只要放了盆就耗液”凑兼容，也不修改Create原配方匹配。

核查依据见[EXT-B-API-01A报告](../../reviews/2026-10-03/heat-api-01a/EXT-B-API-01A.md)。这是锁定Create6.0.10-280的静态核查，不是运行探针通过；完整EXT-B-API-01尚未完成。

## 3. 热值、耗液与余热

旧文档同时写“18个超级燃烧室”和“BoilerHeater返回18”，实际并不等价：Create每个超级燃烧室返回2，普通燃烧室返回1。推荐保留既有明确API合同的**锅炉热等级18**，统一说明为等效9个超级燃烧室的数值热量；不是18个。未来蒸汽模式仍保留等级9，本批不实现。

| 参数 | 推荐值与含义 |
| :--- | :--- |
| 核热返回值 | 18，整数Create锅炉热等级，可配置；停止供热时返回NO_HEAT（-1），不是被动热0 |
| 热量换算 | 首轮1个锅炉热等级对应1HU/t，因此额定18HU/t；这是本模组试验换算，不是Create内置物理单位 |
| 热液能量 | 沿用现有反应堆配置，默认0.5HU/mB，不改反应堆产热/燃耗/冷却合同 |
| 额定耗液 | 默认36mB/t，即720mB/s；全部转成等量冷液，无正常净损耗 |
| 初次预热 | 先储备40有效tick的额定热量再供热，默认消耗1440mB热液并返等量冷液，形成720HU储备 |
| 运行补热 | 每tick按供热额定值扣储备、实际换热补回；BoilerHeater查询只读，不在被查询时再次耗液或计热 |
| 断供/冷液堵塞 | 停止换热，最多使用已支付的40tick（正常20TPS下2秒）余热，随后直接熄灭，不降为普通加热；不因少量进液或重载免费刷新满储备 |
| 无有效负载 | 不转换热液；此前储备最多按剩余余热期散掉。没有锅炉、没有引擎/汽笛或没有有效供水都不正常耗液 |

有效负载指顶部连接Create锅炉底层、锅炉具有引擎或汽笛且供水能形成至少一级有效热量。无需应力网已经带动其他机器；这遵循Create原生锅炉的运行语义。不是仅放一块储罐就满足条件。

Create最终有效等级还受储罐体积与供水限制。要用满18级，需要至少72个储罐方块且持续供水达到180mB/t；本方案不绕过这些限制。首轮换热器按额定耗液，小锅炉/不足供水不会自动返还未利用的热量，护目镜给出限制提示。后续若做负载比例调节，再单列多热源分摊与守恒方案。

配置须有限且有界，0吸热系数等无效组合安全停机。保存精确储备、预热阶段及剩余余热，加载后先验证真实负载再发布热级；卸载/拆除必须通知锅炉重新计算。工质转换前同时检查输入量与冷罐空间，以同一服务端事务提交，模拟能力请求不改变任何状态。事故损坏属于既定后续统一阶段，本批先完成可观察的安全停机，不新增世界破坏。

## 4. 前置材料与制造

不新增序列半成品，也不制造一个只负责Create适配的独立零件。原“模块→适配器”的未实现配方合并为本体直接供热，作为本次待确认调整。

| 配方 | 推荐产出与工序 |
| :--- | :--- |
| 1钢锭 | 切石→2钢管坯，机械锯沿Create原生切石兼容；仅材料，不是可放置管道 |
| 1钢板＋1Create坚固板＋1精密构件 | 工作台竖排：坚固板/精密构件/钢板→1强化钢板，保留原材料关系，替代旧序列设想 |
| 4钢管坯＋2铜片＋1强化钢板 | 工作台3×3：管坯放四角，中行铜片/强化钢板/铜片→1核换热管束 |
| 12钢板＋4铜片＋2耐压接头＋2核换热管束＋1工业传感器 | 21格动力合成器→1核换热器，禁止镜像，无副产物 |

21格为5×5去四角；S钢板、C铜片、P耐压接头、H核换热管束、I工业传感器：

```text
 SSS
SCPCS
SHIHS
SCPCS
 SSS
```

首末行末尾各补一个空格。工序数量全部确定，工作台与动力合成沿原生速度，不设额外加热或机器内加工时间。普通材料引用具体通用标签；强化钢板使用已规划的`c:plates/reinforced_steel`，不混入普通钢板；专用管束使用本模组专用标签。

首台直接/展开成本约20钢锭当量、8铜片、2坚固板、2精密构件、2锡合金焊料和1工业传感器，不含Create零件内部配方成本。Create锅炉、引擎、管道/泵、首次灌液另计。现有燃料包壳路线不因钢管坯出现而重做。

## 5. 实施与最小验证

确认后由PM冻结精确任务卡，复用同级候选。执行者分别承担材料/原生配方素材、设备与热账本；按实际复杂度选模型，只有设备事务和接入需要较高思考强度。不会把尚未确认的方案派发为功能实现。

自动验证只针对：①换热/储备守恒及堵塞/断供/保存恢复；②真实Create锅炉读取18级并受尺寸/水量限制，拆除/重载无残留热；③新材料与制造路线的代表匹配/制品资源。一次相关定向组、一次增量assemble、一次合并复审；不重跑旧全量或材料/燃料整条矩阵。

人工合并为三组：制造与模型/JEI；真实反应堆热液推动Create锅炉并返冷液；断供/堵塞/恢复及拆放重载。到此暂停验收，再接盆加热与完整蒸汽链。
