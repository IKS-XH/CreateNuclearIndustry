## 建议采用的具体方案

推荐一件机器物品放出完整八格，保持离心机式整机搬迁体验；若改为玩家分别制作并搭建机壳和控制器，会额外引入组件配方、成型与配件回收规则，不是本轮推荐。

| 项目 | 已批准行为 |
| :--- | :--- |
| 放置 | 由一次放置生成完整2×2×2整机；朝向决定前脸和带标记的动力口。提前检查八格空间与放置权限，不覆盖既有不可替换方块；不能完整放下时不消耗机器，也不留下残件。 |
| 四周 | 四个大侧面各有2×2个可接物流的位置，共16个水平外表面；每处均可插入任意一种合格原料，也可提取唯一成品，漏斗朝向决定输入或输出。不得从侧面抽走输入原料；成品不能回灌。 |
| 顶部 | 保留顶部投料，四个顶面都能混合输入四料，仅输入，方便沿用溜槽/漏斗/机械臂。 |

| 手工、护目镜、机械臂 | 点击任意机身分块都转交同一库存与状态；右键和潜行退料沿用02D。机械臂继续只投料；成品经侧面漏斗到外置置物台接力，不改反应堆端口合同。 |
| 拆放 | 拆任意一格只回收一次完整机器及库存/进度，其余七格一起移除，不再散落第二份内部物品。扳手收起后改变朝向重放，避免直接旋转单个分块造成错位。 |

任何分块都不是额外生产机：四料、成品、进度、动力只存在于一个主控，七个从属只转交交互。结构缺失或相关区块未加载时暂停加工和自动物流，保留库存，不强制加载区块；清理只处理归属匹配的分块，不能误拆相邻设备。具体生命周期由实施任务约束并定向验证。

部分加载不能当作结构损坏：暂时无法定位主控时，正常玩家拆卸拒绝并提示稍后重试，不凭代理重造库存；直接替换等异常导致缺件时由仍存在的主控保留库存供整机回收。代理只有在主控位置已经加载、并明确不存在归属匹配的主控时才静默清理；主控被强制移除则仍由其唯一回收入口封存库存，未加载代理随后按归属清理。无需限制玩家把设备跨区块摆放，也不引入区块强制加载。

## 21格制造建议

采用离心机同样的5×5去四角形状，推荐 **12铅板＋6钢板＋2完整Create机械手＋1辐射传感器→1台整机**。沿用已有四类制造材料，增加围护和装配机构数量；两台机械手是配件，放置后无需外搭机械手才能运行。

```text
   铅 铅 铅
铅 钢 钢 钢 铅
铅 手 感 手 铅
铅 钢 钢 钢 铅
   铅 铅 铅
```

JSON形状为`" LLL "/"LSSSL"/"LDRDL"/"LSSSL"/" LLL "`；L为`c:plates/lead`、S为`c:plates/steel`、D为`create:deployer`、R为本模组`radiation_sensor`。采用原生`create:mechanical_crafting`，无镜像变体，产1件不可堆叠整机。用户在指定21格制造后明确确认本稿完整方案，12/6/2/1数量现已获批准。

## 模型与后期动画

按2格尺度重画钢制底座、铅灰削角罩、黄铜边框和观察区，保持像素密度；各个水平外表面均有可接漏斗的实体面。底部动力口清晰可见，四周不烘焙限定投料种类的标志。方块间接缝、外壳封口、物品栏和手持缩放都须实际查看预览。

静态机架/底座/罩体与活动装配机构分开建模。推荐两侧装配臂与中央夹具为可动分件，本批在待机位置拼装显示；后续可加入夹持、装配往复动作。源文件记录各部件局部原点、旋转中心、运动轴、可用行程和活动包围范围，给窗口、支架和相邻部件留出空间。静态壳体不能把同一活动件再次烘焙进去。

运行期由主控统一渲染活动部件，从属不重复渲染；视锥裁剪覆盖完整2×2×2设备。渲染使用现有Create/局部模型接入，状态与进度只读取服务端同步结果，动画不能反向推进生产。本批交付可拆分模型、待机装配预览和运动范围说明；具体动画时序后续单独实现。物品模型使用整机静态合成和标准手持尺寸，不直接把世界尺寸当手持尺寸。
