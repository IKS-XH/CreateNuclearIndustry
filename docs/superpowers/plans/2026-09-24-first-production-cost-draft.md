# 首套生产线成本：核算口径

**更新：2026-10-08。** 基础加工、专用设备、燃料、冷却剂、机组和轻量封存配方已按批验收。本文保留整线成本评估方法，不单独授权修改配方；旧250/500mB比较稿及技术审计见[历史草案](../../archive/2026-10-08-document-snapshots/first-production-cost-draft.md)。

| 账目 | 核算内容 |
| :--- | :--- |
| 原版/Create基础设施 | 粉碎、压片、搅拌、洗涤、装配、动力与供热；已有设施可复用，但从零成本必须单列 |
| 专用生产设备 | 离心机、烧结炉、屏蔽装配台及上游材料；按实际制造配方计一次性投入 |
| 首批燃料 | 选矿、制浆、富集、芯块、包壳、焊料、格架及副产物容纳；每列一个组件，不把三格燃料柱算三个组件 |
| 首次充液 | 反应堆与外部回路实际持液量；冷热共享容量只算一次，不把满罐设为新运行条件 |
| 机组与封存 | 反应堆、锅炉、汽轮机/回水及灌封桶/贮存位置；不能只核算第一批燃料即称完整机组成本 |
| 运行与扩建 | 后续燃料、维修、实际损失补液和新增设备；与首建账分开 |

成本定位仍为适中材料投入，以工序与产线搭建为挑战，支持手动搬运、随后自动扩产。现行配方见[配方表](../../recipes.md)，吞吐/寿命及热端参数见实际配置。

按固定实验堆默认每空气格1000mB核算：单燃料列/其余合法空气列共享容量24000mB，三行F-C-F为9000mB，八燃料/中心空列为3000mB。这些是布局敏感性锚点，不是推荐起步布局或新增人工证据。实际最低启动工质还应计管路/设备持液和流量余量。

单格有效燃料高度的默认完好满功率耐久锚点为3小时，三格列基准为1小时；邻接超频、损伤和控制棒改变消耗。不能按组件数量给出无条件持续时长。冷却剂已确定三粉各1＋1000mB水→1000mB，1:1制粉、加工参数100、无需加热，历史备选不再列为待确认参数。

未完成的是整线成本/扩产效率和平衡评估，需按现行资源重新算首台、首批、首次充液和持续补给。不重新确认既有数量，也不据此改动已验收配方；新的实际使用工序单独开卡。
