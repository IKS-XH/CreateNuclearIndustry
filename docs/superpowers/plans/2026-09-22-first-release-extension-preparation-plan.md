## 2. 保持的生产与设备原则

- 首套产线材料投入适中，主要挑战来自工序和搭建；支持手动转运、自动扩产，不以全自动接线作为合成前置。
- 通用材料使用实际NeoForge/Create通用标签。青金石粉由粉碎轮生产，磨石保留原染料工序；整颗宝石/染料不替代粉末。
- 专用烧结最低普通加热，首次燃料不要求先建核机组；现行工序与数量按[配方表](../../recipes.md)和实际资源维护。
- 设备/零件工作台配方使用有序；粗矿块及金属锭拆解保留无序。序列装配谨慎采用，须说明量产和多工序必要性。
- 全部设备保持Create无GUI，优先世界交互、护目镜和原生数值/选项行为；玩家外部漏斗/管路负责物流过滤。
- 热冷冷却剂体积守恒，正常闭环不持续消耗；两种锅炉蒸汽独立真实mB/HU记账，共用一份容量与炉压，不自动改写库存汽种。
- 汽轮机只接受超临界蒸汽，排同一个`steam`，实际排汽计流量，双端共享唯一SU；换热器冷凝回原版水，不另注册乏汽/冷凝水。
- 换热器超临界蒸汽输入/降级供热路线已取消；已有核热与普通蒸汽冷凝保持。不得以蒸汽循环重复获取已付热。
