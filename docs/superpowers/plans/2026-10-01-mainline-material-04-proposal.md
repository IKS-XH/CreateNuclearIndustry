## 目标与依赖

本批建议在现有原版/Create加工入口上增加三个已有策划身份：`tin_wire`（显示名锡条）、`industrial_sensor`（工业传感器）、`radiation_sensor`（辐射传感器）。它们在当前main尚未注册；这次候选只将它们作为装配材料，不赋予检测或主动使用功能。

依据[配方第5.2、6、11节](../../recipes.md)：锡条进入工业传感器；工业传感器直接用于富集离心机、燃料烧结炉，并进入屏蔽装配台所需的辐射传感器。先提供这组共同前置能缩短首台设备路径。离心机仍缺重型轴承，烧结炉仍缺耐火砖；设备本体成本和运行合同后续另批确认，不能把这三件材料的完成称为设备已可用。

其他通用零件可以组成后续批次，但将焊料、管坯、密封环、轴及管网件同时纳入，会扩大本批配方、素材和验收范围。PM推荐先完成这三项共同前置，再补耐火砖、轴承及设备合同。已有工序关系继续沿用，本次需要决定的是具体数量、装配步骤和循环次数。

## 推荐的首轮参数（全部尚未批准）

| 产物 | 输入与数量 | 工序及参数 |
| :--- | :--- | :--- |
| 2锡条 | 1锡锭 | 原版切石机；Create机械锯沿原生切石配方支持与配置，不另设加工速度 |
| 1工业传感器 | 1铁板 + 1锡条 + 1红石粉 + 1电子管 | 铁板为基底，机械手依次加入锡条、红石粉、电子管，再压片；序列装配1轮，100%成功 |
| 1辐射传感器 | 1铅板 + 1工业传感器 + 1电子管 | 铅板为基底，机械手依次加入工业传感器、电子管，再压片；序列装配1轮，100%成功 |

推荐两种装配均无需加热、无副产物和概率失败，各设备沿Create原生加工速度，不设置统一秒数或新的转速/应力规则。不新增传感器逆向拆解配方。装配中间态使用Create原生序列机制保留，JEI展示完整步骤；新的素材及必要中间态沿用已认可SVG风格，由执行者制作。

成本核算例：2个工业传感器消耗1锡锭、2铁板、2红石粉、2电子管；2个辐射传感器从基础材料开始共消耗1锡锭、2铁板、2铅板、2红石粉、4电子管。板材制备、Create设备与动力投入另计；这不是首台核工业设备的完整成本。
