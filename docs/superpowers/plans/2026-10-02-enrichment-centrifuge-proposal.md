## 目标与已有决定

玩家能用原版、Create和已验收材料制造第一台离心机，并从现有铀矿走到一批低浓缩铀粉；贫化铀、尾矿和水均有明确库存或去向。交付包含可运行设备，不以仅有注册物品或方块外壳视为完成。

直接沿用[项目策划第3.4节](../../project.md)、[配方第5.3、8.1、11节](../../recipes.md)及[扩展准备计划](./2026-09-22-first-release-extension-preparation-plan.md)：

- 粉碎粗铀经鼓风机水洗生成精矿与尾矿；水洗环境不按批消耗水。精矿加水、加热搅拌成为料浆，离心机分离两种粉末并返还工艺水。
- 离心机制造按用户2026-10-02最新要求与截图，使用21格动力合成器和重型轴承、精密构件、工业传感器、搅拌器零件（`create:whisk`）、金板、钢板六种配件，取消铜外壳基底和机械手序列装配。各配件已有生产入口，已确认数量与摆法如下。
- 低转速降低生产能力，超速增加维护损耗；本方案将“降低产率”明确为单位时间产量下降，单批产物不随转速丢失。
- 支持手动转运与自动化；核材料保持各自专用身份和本模组标签，不混入`c:dusts/uranium`或普通粉末集合。
- 美术沿用已认可的方正SVG像素风，由执行者制作SVG并导出；方块形状用JSON模型。保留现有69张游戏PNG及冷却剂原图。

## 已确认的设备与交互

采用**单方块密闭立式离心机**：钢灰主体、铜色框架、前面状态窗和转子观察窗，四向水平放置。尺寸占1格；后侧接动力轴，面向机器时左侧接料浆，右侧排水，底部输出两种粉末。顶部不提供接口。

相比多方块离心塔，单方块更适合首条小规模产线，模型、结构检测与布管成本更低。多方块扩容留待后续，不要求玩家搭建级联。只制作设备外壳会留下无法加工的交付，不作为本批方案。

- 前面右键打开简洁面板：料浆与水量、两个只允许取出的产物槽、加工进度、转速、轴承状态和停机原因；工程师护目镜显示同一份状态摘要。
- 料浆输入罐和水输出罐各4000 mB；两个产物槽分别容纳64份低浓缩铀粉和64份贫化铀粉。底部漏斗/漏斗类物品能力可依次取出两槽，玩家可在后续物流中分类；外部不得向产物槽塞物品。
- 左侧流体接口接收料浆，也允许抽回未投入加工的料浆；右侧只允许抽水。提供1000 mB密闭料浆桶，空容器沿用原版桶，支持在对应侧手工整桶转移；不足一桶或空间不足不改动任一方。料浆桶不向世界倾倒，机器和Create容器之间仍可人工搬运。
- 轴承耗尽后停机，在转速为0时用1个已有重型轴承维修，恢复全部轴承寿命；旧轴承不返还。前面显示维修提示，不新增维修材料体系。
- 普通挖掘或扳手取下设备时，机内物料、正在加工批次、进度与磨损随单件机器物品保留，重新放置恢复；不能通过拆放获得免费轴承或重复产物。首轮机器固定运行，不支持活塞推动或Create移动装置搬运；正常存档卸载保留状态。爆炸等原版破坏不承诺库存无损保护，不改变现有世界规则。

## 已确认的首轮数量与速度

| 项目 | 已确认首轮参数 |
| :--- | :--- |
| 洗矿 | 1粉碎粗铀 → 1铀精矿＋1铀尾矿；固定产物，无概率副产；速度沿Create原生水洗 |
| 尾矿存放 | 1铀尾矿经压片 → 1尾矿砖；可放置堆存，无逆向回燃料配方；速度沿Create原生压片 |
| 制浆 | 8铀精矿＋1000 mB水 → 1000 mB铀料浆；最低普通加热，`processing_time=200`，无其他产物 |
| 设备制造 | 下节5×5去四角，10钢板＋6金板＋2重型轴承＋1精密构件＋1工业传感器＋1搅拌器零件 → 1离心机，无副产物，速度沿Create原生动力合成器 |
| 离心分离 | 1000 mB料浆 → 1低浓缩铀粉＋7贫化铀粉＋1000 mB原版水；全部输出必须保留 |
| 额定加工 | 128 RPM时400个有效游戏tick完成一批，即正常20 TPS下20秒；64 RPM为40秒、256 RPM为10秒 |
| 低速与稳定 | 正反转均用转速绝对值决定速度；非零低速按比例减慢，0或网络过载暂停。启动、改变转速或方向后连续稳定20tick才继续，暂停保留进度 |
| 应力 | 基础影响8 SU/RPM；128 RPM占1024 SU、256 RPM占2048 SU，转动时按Create网络计入，不以配方是否堵塞免除负载 |
| 超速维护 | 超过额定128 RPM的有效加工累计轴承磨损；256 RPM累计加工2小时耗尽，192 RPM为4小时；不超过128 RPM本轮不磨损，耗尽暂停加工 |

`processing_time=200`是Create加工参数，不是固定10秒。离心机则使用自己的额定工作量：每有效tick增加`min(abs(RPM), 256) / 128`，达到400完成；现有Create服务器最大转速配置不被修改。若外部允许超过256 RPM，吞吐和磨损按256封顶，应力仍按实际转速计算。

稳定计时和加工均按服务端游戏tick结算，不计算离线时间。轴承每有效tick的磨损为`clamp((abs(RPM) - 128) / 128, 0, 1) / 144000`；只有实际推进加工时结算，不在缺料、堵塞、等待稳定或停机时消耗寿命。新制设备轴承完整，不需要再额外投入一个轴承才能启动。

这些数量是游戏中的首轮平衡参数，不表达真实同位素比例。本批不改变已有燃料组件的耐久或反应堆燃耗；首个组件最终需要多少粉末，仍取决于后续芯块、燃料棒和组件装配批次。

## 已确认的21格动力合成器布局

用户截图及“按照我图片中的布局设计”明确确认以下摆法和输入数量：5×5去掉四角，每个有效格投入1件，共21件；随后确认其余全部方案，每批产1台。

```text
· 钢 轴 钢 ·
钢 金 感 金 钢
钢 金 搅 金 钢
钢 金 精 金 钢
· 钢 轴 钢 ·
```

`·`表示不放动力合成器；钢=钢板×10，金=金板×6，轴=重型轴承×2，精=精密构件×1，感=工业传感器×1，搅=搅拌器零件×1。中轴从上到下为轴承、传感器、搅拌器、精密构件、轴承；两侧各3金板，外侧共10钢板。采用图示固定摆法，不增加普通工作台或机械手制造的替代入口。截图中的动力合成器箭头表示原生连接/输出方向，不另做只有一条输送路径才匹配的配方限制。

钢板输入沿用`c:plates/steel`，金板使用`c:plates/gold`（锁定Create已含`create:golden_sheet`）；专用零件重型轴承和工业传感器使用本模组现有物品身份，精密构件为`create:precision_mechanism`，中央搅拌器为`create:whisk`，不为本次配方另造同义零件或半成品。

PM只读核对Create 6.0.10-280的`data/create/recipe/mechanical_crafting/crushing_wheel.json`，已有相同5×5去四角的21格配方形状，类型为`create:mechanical_crafting`；`plates/gold`标签确认金板身份。中文语言文件中`item.create.whisk`为“搅拌器”、`block.create.mechanical_mixer`为“动力搅拌器”，并已查看`textures/item/whisk.png`与用户图中央零件核对；PM先前将该原料理解为完整动力搅拌器的文字和成本已纠正。本次仅更新设计文档，尚未写JSON或验证实际合成。

## 物料、状态与兼容边界

设备方块实体是库存、批次、进度和磨损的唯一持久化所有者；客户端面板、动画和护目镜仅显示服务端同步结果。Create提供轴网转速与应力，离心机负责自己的加工事务。

启动一批时把1000 mB料浆从输入罐转为机内密闭批次，避免外部抽料后仍然继续生成产物；该批次随保存和设备取下保留。启动前检查全部输出空间，完成时再次检查并一次提交两种粉末和水。任一输出受阻则保留批次、暂停进度和磨损，疏通后继续；不得只产主产品并删除副产物。

所有物品/流体模拟操作只读，实际执行重新检查数量、身份和空间；面板只操作当前有效机器和玩家自己的背包。普通粉末不能冒充核材料，水不能直接进入料浆罐。存档保存配方身份及已开始批次的输入、结果和总工作量，避免配方重载把已扣原料变成另一种产物；未开始的批次采用重载后的配方。

新增范围拟为`uranium_concentrate`、`uranium_tailings`、`uranium_tailings_brick`、`uranium_slurry`及容器、`low_enriched_uranium_dust`、`depleted_uranium_dust`、`enrichment_centrifuge`；取消原候选`incomplete_enrichment_centrifuge`及其素材，不注册无用途的离心机半成品。最终技术ID与现有预留名核对后在实施卡列明。核工艺水使用`minecraft:water`，不新增另一种水。

离心加工使用独立数据配方类型，JEI展示其料浆、两粉、水和额定条件；原生水洗、压片、制浆和制造继续用Create配方。已有反应堆、冷却剂、燃料组件状态及其他材料配方不改动。

本批完成富集，烧结炉、屏蔽装配台、组件组装、冷却剂生产、贫化铀后续用途、辐射/污染、事故和Ponder后续分别安排。贫化铀本批保留为可储存物品，尾矿压砖可堆存，不提前实现屏蔽尾矿块。

## 首台投入与扩产

- 按已确认的单台配方，一台机器直接投入10钢板、6金板、2重型轴承、1精密构件、1工业传感器、1搅拌器零件。展开已验收钢板、轴承、传感器及Create金板加工后，为12钢锭、6金锭、2坚固板、3精密构件、1铁板、1锡条、1红石粉、1电子管和1搅拌器零件；原生Create部件保留其原配方成本。
- 配套复用现有粉碎轮、鼓风机水洗、动力搅拌盆与普通燃烧热源，以及上游零件所需机械手/压片机；设备本体需要21台相连的动力合成器，属于首台产线设施投入，不能漏算为21件配方材料的一部分。配方中央消耗搅拌器零件，制浆仍使用原有完整动力搅拌器。允许桶和手工搬运起步。
- 一批需要8份粉碎粗铀，保留8份尾矿（可压8块砖），得到1份低浓缩铀粉、7份贫化铀粉并回收1000 mB水。首次需提供1000 mB工艺水，可循环回制浆，不因离心重复生成额外水。
- 128 RPM连续供料且输出畅通时约3批/分钟，扣除首次稳定时间；256 RPM约6批/分钟，额外承担轴承维护。两台128 RPM具有相近总吞吐和合计2048 SU，代价是双份机器材料与空间，可以避免超速磨损。
- 双4000 mB罐支持缓冲，不代表必须先灌满才能开机。上游吞吐、两类物品和水的疏通均可能成为实际瓶颈。
