## 已确认的本批目标

用户于2026-10-01明确要求：“钢的制取改为4铁粉+1煤／木炭粉搅拌为5钢粉，钢粉使用熔炉或其他熔炼方式烧成钢锭，铁粉由粉碎轮粉碎铁锭获得”。据此替换旧的铁锭直接加热搅拌出钢锭方案：

1. 铁锭经 Create 粉碎轮加工为铁粉。
2. 煤与木炭分别经粉碎轮加工为煤粉、木炭粉；磨石继续保留 Create 原有染料路线，此设备分工沿用已确认 D-03d。
3. 4铁粉 + 1煤粉或木炭粉，在工作盆中动力搅拌，产出5钢粉。两种碳粉各自提供等价入口；配比与钢粉产量已经批准，不重复询问。
4. 钢粉经熔炉或其他熔炼方式制成合金钢锭。
5. 合金钢锭压成现有 `steel_plate`，为已实现的维修功能及后续零件、设备提供生存材料来源。

本批新增身份为 `iron_dust`、`coal_dust`、`charcoal_dust`、`steel_dust`、`steel_ingot`；显示名沿用“合金钢”体系。铁粉与 Create 的粉碎粗铁是不同加工形态，分别使用 `c:dusts/iron` 与粉碎粗矿标签，不互相冒充。钢粉加入 `c:dusts/steel`，其他粉末、钢锭和既有钢板按对应具体通用标签接入。新增粉末子标签汇入 `c:dusts`，标签追加不得覆盖其他提供者。

不改反应堆机制、维修数值、铅锡链、设备、冷却剂或辅助模拟器。不新增钢锭回粉、钢粉拆回铁粉等用户未要求的逆向路线。
