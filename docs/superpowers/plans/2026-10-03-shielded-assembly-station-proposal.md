# 燃料02D：屏蔽装配台与燃料组件直接装配方案

**状态：2026-10-03用户确认完整方案，已实现为候选，等待四组手测。** 见[02D交付页](../../reviews/2026-10-03/fuel-02d/README.md)与[实施卡](./2026-10-03-ext-a-fuel-02d.md)。02C已[全部验收合入main](../../reviews/2026-10-03/fuel-02c/ACCEPTANCE.md)，02D功能仍在同级候选。目标是用现有四种材料生产可直接装入既有换料端口的正式新燃料组件，接通首批燃料制造出口。

## 已确认约束

- 烧结燃料芯块＋燃料包壳管＋锡合金焊料＋钢格架直接制新燃料组件；取消独立新燃料棒工序，组件直接原料不含工业传感器。
- 保留专用烧结与屏蔽装配设备，不从低浓缩铀粉跳到组件。设备无独立GUI，手工搬运和Create自动化都能使用。
- 复用`fresh_fuel_assembly`正式身份、单件堆叠和既有耐久；不改反应堆寿命、换料权限或状态所有权。
- 9格设备制造采用工作台；外观沿已认可的SVG色板与Create多边形风格，避免过小模型。

上述材料关系与交互原则直接沿用。以下数量、转速、耗时、应力、接口和外形均已随完整方案获得用户确认。

本轮比较两种外形：推荐一格密闭装配台，四料共用入口，接口和保存行为简单；两格或小型多方块可以放大内部动作，但会增加占地、拆放和接口代理成本。当前只有四料合一、单一成品的工序，一格即可容纳；若用户希望强化视觉规模，可在批准前改为两格。

## 已确认加工参数

| 项目 | 已确认参数 |
| :--- | :--- |
| 一批输入 | 8烧结燃料芯块＋4燃料包壳管＋2锡合金焊料＋1钢格架 |
| 一批输出 | 1浓缩铀燃料组件，即既有`fresh_fuel_assembly`；全新、满耐久、无副产物 |
| 运行条件 | Create转轴供能，不需燃烧室、流体或额外燃料；正反转均可 |
| 最低转速 | 32RPM；不足时暂停 |
| 速度与应力 | 4SU/RPM；64RPM每批20秒/256SU，128RPM每批10秒/512SU，256RPM每批5秒/1024SU |
| 超出额定范围 | 工时增速最多按256RPM计算，应力仍按实际绝对转速计算；不新增磨损/维修 |
| 缓存 | 四种输入各64件，成品槽仅1个组件；自动拒绝错误物品及任何已有组件回灌 |

时间按20TPS有效加工计算；32RPM为每批40秒。加工开始不预扣原料，完工时再次检查四料齐全与空输出，在同一服务端事务中扣四料并放出一个全新组件。无动力、网络过载、低速或成品满时暂停且保留进度；手工退料导致不足一批时清零进度，剩余物品完整返还或保留，不允许悬空工时套用到下一批。

该数量把“一束组件”表达为四根包壳、每根两块芯块的一次密闭装配，属于游戏首轮参数，不引入新的燃料棒物品或真实核工程计算。

## 设备制造、布局与外观

`shielded_assembly_station`一件放出一格完整设备，朝向只改变外观，不改变接口规则。工作台3×3有序合成产1台，动力合成器可沿Create原生工作台配方兼容使用：

```text
铅板   钢板     铅板
钢板   机械手   钢板
铅板   辐射传感器 铅板
```

总计4铅板＋3钢板＋1完整Create机械手`create:deployer`＋1辐射传感器。全部输入已有生存来源；配方中的机械手是制造配件，放置后无需在外面再架一台机械手。

外观建议为占满一格的钢制底座、铅灰削角密闭罩、黄铜边框及正面状态观察窗；顶部留明显投料口，底部是转轴接口。模型采用原生多面体，延续既有SVG素材；状态灯与底部转轴表达运行，不追加复杂装配动画。物品栏显示立体设备，手持使用标准方块缩放。

## 无GUI操作与物流

| 位置或操作 | 已确认行为 |
| :--- | :--- |
| 顶部 | 唯一自动输入面，四料共用一个入口、自动归入对应缓存；可使用溜槽/原版漏斗，亦提供仅投料的Create动力机械臂交互点 |
| 四个水平侧面 | 外置漏斗或通用物品物流都能从同一个成品槽提取，由玩家选择接哪一侧；机械臂从外置置物台接力取成品，不设机身过滤槽 |
| 底部 | 只输入动力，不提供物料能力 |
| 手持原料右键 | 向对应缓存投入手持数量，满槽只接受能容纳部分，其他物品不改变库存 |
| 空手右键 | 取出成品；没有成品时只显示缺料/转速/输出状态，不打开菜单 |
| 潜行空手右键 | 按芯块、包壳、焊料、格架的固定次序，取回第一个非空输入槽的物品；每次只处理一槽 |
| 工程师护目镜 | 显示四料库存/需求、成品占用、速度、进度和等待原因 |

四种材料可混合送入同一个顶部入口，不强迫每种材料独占一个面。成品可用侧面漏斗送到置物台，再由既有动力机械臂送往换料端口；反应堆换料端口仍维持只支持玩家/已接入机械臂的原有限制。锁定Create默认机械臂点只查询顶面能力，因此本批机器交互点只承诺投料；不额外实现按机身四侧选择的机械臂输出点。

本批让新燃料在密闭机器内装配，并使用原生物流搬运材料和新组件；屏蔽机械臂、高放物流、辐射/污染与乏燃料处理仍按后续阶段安排。内容清单里“支持专用机械臂”的表述不作为本批新燃料自动化的额外前置，本次确认同步这一阶段边界。

## 保存、拆放与异常边界

- 真实输入`ItemStack`、唯一输出`ItemStack`及加工进度只由设备方块实体持有；客户端只显示同步信息。
- 退出/重进、区块卸载、停转、变速不重置合法库存或复制产物；离线不补算加工。
- 普通挖掘与潜行扳手收起时，将完整库存/进度封存在唯一机器物品中，重新放置后恢复；不得再额外掉一份内部物品。沿用既有生产设备的携带合同与防重复回调处理。
- 旋转设备不改变顶进、侧出、底部动力规则。多个侧面或多个物流同时取料仍共享唯一成品槽；模拟插入/提取不得改变状态。
- 四材料配方不接受旧组件、乏燃料、生芯块或铀粉来修复/补满耐久。成品为新建正式物品，损伤值0，不新增温度、完整度或燃耗副本。
- 数据包重载后若当前库存不再符合配方，保留物品并停止加工、清除失效工时；不把输入静默删除或转成其他材料。
- JEI显示设备制造与4输入/1输出、最低转速及参考耗时；没有独立玩家库存面板。

## 成本与吞吐核对

单组件新增消耗4包壳＋1格架，相当于6钢板；另需2焊料，相当于一批3锡锭＋1铅锭所得4焊料的一半。实际首次仍需制作整批焊料，剩2件留下一批。

8烧结芯块来自8低浓缩铀粉，即8批已确认富集：合计64精矿、56贫化铀粉副产物，并回收8批各1000mB水。这里统计精矿，不把概率粉碎产物换算成未经核对的矿石数；原料路线与副产物数量不因装配改变。

单台128RPM离心机和单台烧结炉各需160秒提供8份原料；建议装配台64RPM用20秒完成一组件，可先小规模生产，再并联上游扩产。首次还需上述装配台、上游既有设备及动力/物流，不能把运行原料说成首建总成本。组件寿命沿既有反应堆合同，不用于补偿配方成本。
