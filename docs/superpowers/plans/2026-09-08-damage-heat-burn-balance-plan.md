## 1. 已确认的共同合同

对同一燃料列，在相同布局、控制棒深度、燃料类型、高度与超频参数下，以完好状态为基准：

```text
D = 1 - clamp(fuelColumnIntegrity, 0, 1)
H(D) = 1 + (Hmax - 1) × D
B(D) = 1 + (Bmax - 1) × D
本 tick 新生裂变热 = 未叠加损伤的裂变热 × H(D)
本 tick 计划燃耗 = 未叠加损伤的燃耗 × B(D)

reactor.fuelColumnDamageHeatMultiplier = Hmax，默认 2.0
reactor.fuelColumnDamageBurnMultiplier = Bmax，默认 3.0
有效配置：两者有限，且 1 < Hmax < Bmax
```

“增长更快”比较无量纲倍率对损伤程度的斜率，不比较 `HU/t` 与燃料单位的绝对数值，也不新增随时间变化的加速度公式。配置表示满损伤终点，不是额外加成或斜率。

| D | 默认 H(D) | 默认 B(D) | H(D)/B(D) |
| :--- | :--- | :--- | :--- |
| 0 | 1.00 | 1.00 | 1.000000 |
| 0.25 | 1.25 | 1.50 | 0.833333 |
| 0.50 | 1.50 | 2.00 | 0.750000 |
| 0.75 | 1.75 | 2.50 | 0.700000 |
| 1.00 | 2.00 | 3.00 | 0.666667 |

表中效率仅比较有足够燃料、非零基准功率且未被产热上限截断的裂变热/燃耗。产热截断后不退还燃耗，不承诺实际可利用热量或 SU 同比增加。完整度归零不自动停止运行；耗尽、插棒、余热、失效传播、卡死、维修和融毁状态继续遵守原合同。不得把损伤倍率再乘到缓存余热、传播公式或已扣燃料上；超频与损伤倍率分别结算。

配置缺项先补各自默认值，再联合检查。服务端加载/已有重载流程遇到非法组合时，整对回退到 `2.0/3.0` 并给出一次可诊断告警；同一非法配置不得每 tick 重复刷日志。纯模拟参数入口直接拒绝非法组合。合法配置从加载完成后的下一次模拟结算生效，无需重新组装反应堆，不新增重载命令。倍率由配置和完整度派生，不持久化第二份倍率，不补燃料、不追溯旧燃耗、不恢复完整度、不重置事故进度。
