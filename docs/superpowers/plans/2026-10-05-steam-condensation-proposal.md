## 1. 沿用的已确认方向

- 复用既有`nuclear_heat_exchanger`增加冷凝模式，不新增独立冷凝器、多方块或配方。
- `steam`来自汽轮机排汽，冷凝产物是`minecraft:water`；冷凝不消耗或产生Create应力，也不提供锅炉加热。
- 模式按输入工质选择且互斥。首期核热模式继续可用，本批不接入超临界蒸汽降级供热或工作盆加热。
- 用户于2026-10-05明确修改：只有设备正上方一格直接接触水、雪、冰、浮冰或蓝冰时才能冷凝；雪、冰、浮冰会融化为水，单格水会汽化蒸发。原周围3×3×3扫描和冷源不消耗建议作废。无冷源或出水受阻时停止转换，保留输入。
- 无GUI，沿用世界接管和护目镜；所有新增数值放SERVER配置。不研究旧档迁移。

依据：[项目策划](../../project.md)4.2/4.3相关冷凝条款、[流体清单](../../content-catalog.md)和[汽轮机回路](../../recipes.md#15-超临界汽轮机与应力输出部件)。

### 2.1 冷源消耗量（已确认）

按本机成功冷凝的**输入蒸汽mB**累计消耗，低流量会延长冷源寿命；暂停时不消耗。已批准首轮值如下，都是游戏平衡试验值，全部可配置。

| 顶部冷源 | 累计处理量 | 达到后 |
| :--- | ---: | :--- |
| 雪块 | 100000mB | 顶格改为水源方块，开始新的水冷却阶段 |
| 冰 | 100000mB | 顶格改为水源方块，开始新的水冷却阶段 |
| 浮冰 | 900000mB | 顶格改为水源方块，开始新的水冷却阶段 |
| 水源方块 | 100000mB | 顶格水汽化为空气；由原版水流规则处理周围水的补充 |
| 蓝冰 | 不消耗 | 持续作为冷源 |

默认54mB/t、正常20TPS下，100000mB约对应93秒实际满流量工作；浮冰阶段约13.9分钟。雪/冰/浮冰融化后得到的水还可以继续冷凝至水阶段用尽。数量以实际累计流量结算，不能按墙钟时间强行消耗。

水限定为顶格原版水源方块，流水和含水方块无效。孤立水格蒸发后设备暂停，有邻近水补充的场景交由原版机制处理，不额外给水池无限冷量或生成水。默认“雪”使用雪块，不把雪层当作完整雪块。

冷源变化只作用于本机正上方一格；融水/蒸发最多消耗当前冷源可承担的实际冷凝量，达到边界后下次转换重新检查。simulate、输入接收和出水抽取都不得独立触发融化。冷源消耗进度与当前版本的正常保存加载一并处理，不能每次重进世界刷新寿命。

## 3. 直列、模式与液体安全

- 沿用现有同向首尾直列、最多16台、仅两端接管的玩法。背面橙色端收蒸汽，正面蓝色端出水，各台可使用共享蒸汽及水罐空间；中段接口规则与现有核热模式相同。
- 全列空闲时首份实际输入选定模式；SIMULATE查询不能锁模式或改库存。尚有任一模式液体时拒收另一种工质，不把水和冷却剂合并成无类型数字。
- 核热模式转换到冷凝前须排空两侧库存并等现行余热归零；冷凝模式必须撤销Create锅炉及专用锅炉供热，不允许拿冷凝蒸汽再次发热或发电。
- 玩家把已装不同工质的机器首尾拼在一起时，整列暂停并显示“工质模式冲突”；原库存保留，拆开冲突段可恢复。拆机只带本机真实份额；不复制整列库存或冷凝小数尾量。
- 有输出空间才原子扣蒸汽、加水。回水罐满时不再转换；尚有入口空位可以暂存蒸汽，入口也满后拒收。护目镜明确显示无冷源、出水满、入口空、模式冲突与实际冷凝量。
- 回收率支持配置为低于100%，使用有界小数尾量累计，避免小包流量逐包取整造成额外损失；尾量归属单机并随当前版本正常保存，不因分拆/重组重新赠送产物。默认100%不制造额外水，也不产生转换损失。
- 每台只结算自己的每tick额度，同列总吞吐为满足顶部冷源条件成员的额度之和；不能由多端口回调或重复结算放大。

## 4. SERVER配置建议

追加到既有`create_nuclear_industry-heat-exchanger.toml`，保持核热参数的现行含义。以下键已批准，尚待实现，当前还不能作为现有可用键使用。

| 建议键 | 默认 | 取值/单位 |
| :--- | ---: | :--- |
| `condensationRateMbPerTick` | 54 | 正整数，mB/t/台 |
| `condensationRecoveryPermille` | 1000 | 1～1000，千分比；1000即100% |
| `condensationSnowMeltAfterMb` | 100000 | 雪块融化前累计冷凝蒸汽量，mB |
| `condensationIceMeltAfterMb` | 100000 | 冰融化前累计冷凝蒸汽量，mB |
| `condensationPackedIceMeltAfterMb` | 900000 | 浮冰融化前累计冷凝蒸汽量，mB |
| `condensationWaterEvaporateAfterMb` | 100000 | 水源蒸发前累计冷凝蒸汽量，mB |
| `condensationSteamCapacityMb` | 4000 | 每台蒸汽容量，mB |
| `condensationWaterCapacityMb` | 4000 | 每台水容量，mB |

冷源标签使用`create_nuclear_industry:condensation_cold_sources`。默认仅上述五类方块；雪使用雪块，水仅水源。标签扩展应同时定义消耗规则，不能让未定义的冷源自动获得无限寿命。相关配置变化不能生成存量、截断已收液体或把已有工质重新解释成另一模式。
