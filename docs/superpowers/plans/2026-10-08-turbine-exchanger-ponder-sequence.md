# 汽轮机与换热器：后续功能和思索排期

**状态（2026-10-09）：** 工作盆02R1、烧结炉03及汽轮机思索/取景复看均已通过用户手测，净功能和教学整合main。[换热器五幕05候选](../../reviews/2026-10-09/heat-exchanger-ponder-05/CANDIDATE.md)已按用户反馈整改并提交`f4aa143`，R3/R3c定向验证及独立复核通过，等待集中复看。本文件记录排期，实施以具体卡为准。
**维护者：** 用户任命的现任项目经理；实现由执行者承担，PM负责计划、审查、验收与Git。

## 已确认安排

1. 先完成汽轮机思索。沿上轮建议围绕搭建、通汽与动力输出、流量与效率准备情景，讲解现有三档规模、核心先行辅助包壳、双轴共享应力及启动门槛；不修改汽轮机机制。
2. 用户要求先补齐换热器的工作盆供热，与汽轮机教学集中测试，并纠正为有盆即持续超级加热，不探测加工状态。按[EXCHANGER-02R1](./2026-10-08-ext-b-exchanger-02r1-continuous.md)替换旧批次计费，默认4mB/t，断流或冷满立即停热；随后补齐烧结炉同一热源。三项已于2026-10-09通过用户手测并净整合main。
3. 汽轮机教学与工作盆功能分别通过集中手测后，为换热器制作分情景思索，分别介绍它的不同用途。蒸汽冷凝回水属于既有换热器功能，不作为独立设备教学插入第二步之前。

该安排替代此前“等待汽轮机播放通过再实现工作盆供热”的依赖。反应堆可变结构、辅助热、二级耐压、事故/辐射及动画等其他主线仍不自动接续；首发前不研究旧存档兼容。

## 换热器功能边界

- 用户随后明确取消换热器输入超临界蒸汽的功能。原“超临界蒸汽→蒸汽并供热”规划撤销，不实现入口、专属配置或教学；只接受热复合冷却剂进行核热换热、普通 `steam` 进行冷凝回水。现有实现已拒收超临界蒸汽，不影响汽轮机入口或锅炉双汽库存。

- 已有独立核热供Create锅炉、定向冷热循环与同向直列共享库存；已有高压锅炉底部内置换热器；已有蒸汽冷凝回水。
- 已验收工作盆与顶部燃料烧结炉的持续热源；本轮只制作换热器教学。无GUI，冷热液体积1:1、服务端唯一热账本与查询无副作用继续适用，不改变已验收锅炉/汽轮机的热工与效率参数。
- 原[工作盆接入核查](./2026-10-04-heat-exchanger-basin-preparation.md)已按现行源码完成。固定成本按一个超级燃烧室的锅炉热级计，默认2×huPerLevel HU/t；有盆即耗热，空盆、缺料、停转或加工受阻不改变负载，断流不使用余热续烧。旧按批次方案已由02R1替代。
- 持续负载只按顶部设备存在判断，空盆/空炉、缺料、停转或输出堵塞照常耗热；不得免费供热或复制另一套配方引擎。
- 工作盆耗热及新增运行参数按既有用户要求进入配置，不直接复用锅炉18级数值作为配方热级或耗热单位。

## 换热器思索建议分场景

以下是教学划分建议，具体镜头、模板与文案在功能定稿后整理，不提前演示未实现行为：

| 情景 | 聚焦内容 |
| :--- | :--- |
| 独立供热与冷热循环 | 热液入口、冷液出口、同向直列以及给Create锅炉供热 |
| 高压锅炉内置换热 | 换热器作为底部结构、与再加热段形成有效热力回路；简短衔接已验收锅炉教学 |
| 工作盆与烧结炉加热 | 顶部设备摆放、冷热液回路、持续负载及实际加工热级；烧结炉功能验收后纳入 |
| 蒸汽冷凝回水 | 蒸汽输入与回水、顶部冷源、冷源消耗及独立回水管路 |

文案保持短句，只讲设备特有操作与规则，删除开发措辞和Create基础常识。同一时刻只显示一段正文；主要端口和去向放在可见侧。不单独追加重复的停机/排查页。
