## 已确认的首轮参数

| 产物 | 输入和工序 | 已确认参数 |
| :--- | :--- | :--- |
| 1石英粉 | 1下界石英经磨石；粉碎轮沿Create原生磨石配方回退也可处理 | `processing_time=100`；无副产物 |
| 4耐火砖 | 1原版砖块 + 1黏土球 + 1石英粉，在工作盆中动力搅拌 | 最低普通加热`heated`；`processing_time=100`；无副产物 |
| 1重型轴承 | 1坚固板为基底，机械手依次加入1钢锭、1精密构件，最后压片 | 序列装配1轮、100%成功、无需加热、无副产物，设备沿Create原生速度 |

“砖块”明确为`minecraft:bricks`，即4个红砖合成的方块，不是1个`minecraft:brick`；黏土为`minecraft:clay_ball`，不是黏土块。耐火砖采用表中三原料直接加热搅拌，本批不另加生坯及熔炉烧制路线。

石英输入为`c:gems/quartz`，产物加入`c:dusts/quartz`及父`c:dusts`；耐火砖消耗具体石英粉标签，原矿石、原石英和错误粉末不能替代。钢锭使用已批准的`c:ingots/steel`；坚固板和精密构件使用`create:sturdy_sheet`、`create:precision_mechanism`。标签采用追加语义，不覆盖其他提供者。

最低普通加热指有燃料正常燃烧的烈焰人燃烧室；无热和阴燃不满足。超级加热也满足最低门槛，不为本批添加产率或速度奖励。加工参数100不是固定5秒，不新增转速或应力覆写。轴承的100%仅指新增轴承装配，不改变Create精密构件自身的概率配方。

新素材直接沿用已认可的方正SVG像素风：石英粉、耐火砖、重型轴承及半成品共4项，由美术执行者绘制。保留全部65张旧游戏PNG及已回退的8项冷却剂原图；不重新询问既有风格选择。
