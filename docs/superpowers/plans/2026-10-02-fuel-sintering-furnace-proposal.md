## 已确认要求

按[配方8.2及11节](../../recipes.md)、扩展准备计划D-03b：低浓缩铀粉由Create压片机制生芯块，再进专用密闭烧结炉；普通燃烧的烈焰人燃烧室满足首发最低热级，无热/阴燃不足，超级加热不额外提速。普通熔炉、高炉和鼓风加热不能替代此工序。所有设备无GUI，允许手动转运并保留自动化，原材料从原版/Create及已验收产线获取。

本页数量、时间、形状、制造布局和运行细节均在本次整套确认范围内，包括制造与外置供热共需两台完整燃烧室；不再重复索取同一批准。

## 已批准配方与成本

| 环节 | 本批合同 |
| :--- | :--- |
| 生芯块 | 1低浓缩铀粉经Create压片机产1生燃料芯块；沿用原生压片速度，无副产物、无需加热 |
| 烧结 | 1生燃料芯块产1烧结燃料芯块；400有效服务端tick，即正常20TPS时20秒；一次加工1件，无副产物 |
| 制造炉体 | 9格Create动力合成器，4耐火砖＋3钢板＋1完整烈焰人燃烧室＋1工业传感器，产1台；无副产物，沿用原生合成速度 |

已批准3×3制造布局：

```text
耐火砖  钢板    耐火砖
耐火砖  燃烧室  耐火砖
钢板    传感器  钢板
```

制造消耗的是已捕获烈焰人的`create:blaze_burner`，不是空燃烧室。**运行时还需在炉底另放1台完整燃烧室，所以首台可运行产线总共需要2台完整燃烧室**，另备Create正常燃料；该成本已随整套方案获批。4耐火砖、钢板和工业传感器均有现成生产路线，无需新增中间材料。

一台128RPM离心机每20秒产1低浓缩铀粉；按上述1:1和20秒烧结，一台炉的理想吞吐与一台额定离心机相配，256RPM离心机可对应两台炉。这里只比较加工吞吐，不含传输延迟和烈焰人补燃料；首个燃料组件总成本待后续装配配比确定。

## 无GUI设备与接口

- 炉体宽1×深1×高1，放在外置烈焰人燃烧室正上方，整套供热设备总高2格。炉体不接转轴、不计应力，热量由下方Create燃烧室状态提供；燃料投喂沿用燃烧室原生操作与自动化。
- 顶面输入生芯块，四个水平面输出烧结芯块，底面留给热源、不开放物品接口。机身不增加过滤槽，玩家用黄铜漏斗或外部物流选择输出面；本批无流体接口。
- 输入与输出各一个64件槽，接受本批对应芯块，不允许错误物料占槽。玩家持生芯块右击顶面，按剩余容量投入；空手右击顶面取回生料，空手右击四侧取成品，均以背包/手持实际可接收量为限。自动化顶面只投料、四侧只取成品。
- 工程师护目镜显示输入/输出数量、当前热源是否达标、当前进度和等待原因；不提供独立库存/控制面板。

## 加工与保存

服务端保存唯一库存和0..400tick进度。输入存在、下方热级达标且输出可接收时才推进；完成时原子扣1输入、增1成品，失败不扣料。普通加热与超级加热同速；缺热、缺输入或输出满时停止，不继续累计产物。

断热和输出堵塞保留已有进度，恢复条件后继续。手动取走全部生料时清零该件加工进度，不凭空保留已取出物品的工时；部分取料且仍有同种生料时保留进度。保存退出、区块卸载不计算离线产量，重载恢复库存与进度并重新检查热源。

生存模式普通挖掘或潜行扳手回收恰好1台携带库存和进度的炉子，重放恢复；不同时散落第二份库存。空机器创造拆除不留残余。暂不增加设备磨损、维修耗材、辐射、余热、超热加速或其他配方。

## 外观与技术边界

沿用已认可的Create配色：单格矮八棱炉体、暗灰钢壳、黄铜箍、耐火内衬和前侧窄观察窗；有达标热源时炉窗显示亮色，停热时变暗。使用SVG纹理与JSON模型，不使用生图模型；物品为完整立体炉体，常规手持大小。侧面留足漏斗连接空间。

沿用正式规划ID：`green_fuel_pellet`、`sintered_fuel_pellet`、`fuel_sintering_furnace`，对应生燃料芯块、烧结燃料芯块、燃料烧结炉。核材料保持专用身份，不加入普通铀粉标签。专用烧结配方支持JEI显示输入、输出、最低热级与时间。

[锁定版本源码核查](../../reviews/2026-10-02/fuel-02a/design-probe.md)确认Create `BlazeBurnerBlock.getHeatLevelOf`与`HeatCondition.HEATED`可表达门槛：FADING/KINDLED/SEETHING通过，NONE/SMOULDERING拒绝；按每tick真实状态读取，不创建另一套燃烧燃料账本。1:1压片可直接使用`create:pressing`。这是静态可行性，不是游戏验证。
