# 离心机集群布置与模型优化讨论稿

**状态：用户确认两格高，并修正为顶部进浆、四周自由接输出，进入[01D实施](./2026-10-02-ext-a-fuel-01d.md)。** 2026-10-02用户确认“离心机的工作手动测试通过了”，随后要求去掉四周过滤槽、优化五面接线对集群部署的限制，并改成接近Create的多边形机械外观。候选原HEAD为`987f640`，01C功能提交为`b7377fb`。本次记录运行手测通过，不把该答复扩写为制造、旧素材和所有历史清单逐项通过；整批暂不合入main。

## 已确认与未决边界

- 已确认：固定两格高的一体机，取消全部机身过滤槽，物品过滤交给Create黄铜漏斗；减少扩产时每台周围的物流占用；采用有真实几何层次的Create式多边形外观；继续无独立GUI。
- 用户对完整推荐方案的修正是“应该从顶部输入浆料，另外四周的几个面应该由玩家使用黄铜漏斗或者管道自己决定输出产物”。因此上下两段的四个水平面都提供两粉和回收水的输出能力，玩家决定在哪一面接什么；不固定正面出粉或顶部排水，不保留机器自身过滤。
- 保持已批准的21格制造成本、每件产一台、两罐/两粉槽容量、每批物料、速度/应力/磨损和轴承维修条件。增加外形尺寸不自动增加产能，也不新增集群控制器或共享库存。

## 现有实现与只读依据

当前离心机模型只有`from [0,0,0]`至`to [16,16,16]`的整立方体；换贴图不能形成转鼓、支架等轮廓，需要重做模型几何。资源仍按Minecraft1.21.1模型体系，沿用SVG制作贴图，不使用生图模型。

当前`CentrifugeBlockEntity.PortItemHandler`向每个有效面暴露两个产物槽，均只允许提取。锁定Create6.0.10-280的`FunnelBlockEntity.activateExtractor/getAmountToExtract`经`InvManipulationBehaviour.extract`调用`ItemHelper.extract`；后者按槽位扫描，无过滤黄铜漏斗可依次抽出两种粉。它不会保证一批产物交替出料，但不需要两只漏斗才取尽两槽。由此可先合并到公共产物带，再按需要用Create设施统一分拣。此处是源码核查，合流产线吞吐仍需新布局验收。

技能实际用于本次评审：`minecraft-modding`核对锁定NeoForge/Create能力与方块生命周期，`minecraft-testing`划定新增结构的守恒/兼容与客户端检查边界，`minecraft-resource-pack`核对模型几何。只读代理使用高速模型；未改功能文件、未运行构建/测试/游戏。外观方向参考[Create官方项目说明](https://github.com/Creators-of-Create/Create#readme)的可见机械组件组合和世界内交互；具体造型属于本项目建议，不声称是官方设计。

## 三种路线

| 路线 | 玩家布置 | 收益与代价 |
| :--- | :--- | :--- |
| 保留单格并重做模型 | 单格机身，一只漏斗合并两粉输出 | 最快，旧存档改动少；合理布置后左右同样能留空，但造型空间较紧 |
| **推荐：宽1×深1×高2，一件放出上下两格** | 一件离心机直接放出完整立式机器，无需另外搭壳 | 占地仍一格，能表现转鼓与底座，左右紧贴成排；需要成对放置/拆除和旧机迁移 |
| 玩家拼装大型多方块 | 转鼓、机壳、控制/物料口分开搭建 | 可规划共享接口，但必须另定尺寸、成本、规模与吞吐关系，实现和验收范围明显扩大 |

用户修正后的实施接口如下，优先于上轮推荐的固定前后布局。两格本身不减少物流通道；玩家可以选择一只漏斗合流，也可以在不同高度/面分别接管道和过滤漏斗。

| 位置 | 功能 |
| :--- | :--- |
| 下段底面 | 唯一动力输入，延续底部传动 |
| 上段顶面 | 唯一料浆输入；保留手工桶操作及抽回未处理料浆，不输出水或粉 |
| 上下两段四个水平面 | 每面可抽回收水及两种粉，水与粉均只输出；由接入的管道/漏斗决定取什么，外部不得插粉、灌水或从这里灌入料浆 |
| 下段正面 | 与其他水平面相同，另外保留停转轴承维修；空手取粉适用于各水平面 |
| 两段内部接面、下段底面及无方向查询 | 不提供物料，底面只接动力 |

顶部料浆与侧面水接口只暴露各自流体，不在一份侧面handler混放两罐。此稿不承诺外部相邻管线会自动隔离；接管与泵向仍按Create规则，玩家需避免把供浆和回水总管连在一起。成排机器可共用顶部供浆线，在上下两层侧面安排水线和产物线，底部统一传动；最终密度与吞吐用短排代表场景检查。

## 推荐造型与交互

上部为八棱转鼓外壳，配上下金属箍、收口顶盖、窄观察窗；下部为较厚的轴承底座和可辨认的料口。使用灰色金属、少量黄铜紧固件和像素质感，让轮廓、接缝和运动部件承担细节。转子工作状态可通过可见转动表现，停机/堵塞由护目镜补充，不增设备面板。物品栏仍显示完整机器的立体缩略模型，手持使用合适的缩放。

详细模型由资源执行者制作可查看预览后再交客户端验收，不以纯贴图替代几何变化；外壳不画成只有特定水平面能接料的固定标识。

## 建议兼容与验证范围

一件放置两格，空间不足不消耗物品或覆盖方块。下段持有唯一库存、批次、磨损；上段接口转交同一状态。拆任一半只回收整机一次，另一半随之移除，不能复制库存/机器。无论暂停、断电或读档，两半都不各自加工。

旧单格实例不自动覆盖上方方块；保留原物料、批次和磨损，提示用扳手收起后重新放置为两格设备，迁移前暂停加工。历史面过滤字段忽略，不把已经移除的规则继续作用在物流上。

按01D精确卡实施。自动只检查受影响的成对放置/拆除、共享状态/守恒、旧快照兼容与一次增量打包；不重复既有配方和速度/磨损整套用例。客户端集中检查新外观、短排产线的一批实际合流出料与独立进排液、任一半拆放及旧机迁移，不要求重测已通过的整套离心流程。
