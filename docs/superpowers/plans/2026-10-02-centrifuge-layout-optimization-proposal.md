# 离心机集群布置与模型优化讨论稿

**状态：待用户决定结构路线，尚未派发实现。** 2026-10-02用户确认“离心机的工作手动测试通过了”，随后要求去掉四周过滤槽、优化五面接线对集群部署的限制，并改成接近Create的多边形机械外观。当前候选HEAD为`987f640`，01C功能提交为`b7377fb`。本次记录运行手测通过，不把该答复扩写为制造、旧素材和所有历史清单逐项通过；外观已有明确优化要求，整批暂不合入main。

## 已确认与未决边界

- 已确认：取消机身侧面过滤槽，物品过滤可交给Create黄铜漏斗；减少扩产时每台周围的物流占用；采用有真实几何层次的Create式多边形外观；继续无独立GUI。
- 待确认：保留单格、固定两格一体设备或玩家拼装的大型结构；具体接口布局及旧单格设备迁移。推荐顶部过滤槽也随侧面一并取消，避免保留另一套机器筛选操作。
- 建议保持已批准的21格制造成本、每件产一台、两罐/两粉槽容量、每批物料、速度/应力/磨损和轴承维修条件。增加外形尺寸不自动增加产能，也不新增集群控制器或共享库存。

## 现有实现与只读依据

当前离心机模型只有`from [0,0,0]`至`to [16,16,16]`的整立方体；换贴图不能形成转鼓、支架等轮廓，需要重做模型几何。资源仍按Minecraft1.21.1模型体系，沿用SVG制作贴图，不使用生图模型。

当前`CentrifugeBlockEntity.PortItemHandler`向每个有效面暴露两个产物槽，均只允许提取。锁定Create6.0.10-280的`FunnelBlockEntity.activateExtractor/getAmountToExtract`经`InvManipulationBehaviour.extract`调用`ItemHelper.extract`；后者按槽位扫描，无过滤黄铜漏斗可依次抽出两种粉。它不会保证一批产物交替出料，但不需要两只漏斗才取尽两槽。由此可先合并到公共产物带，再按需要用Create设施统一分拣。此处是源码核查，合流产线吞吐仍需新布局验收。

技能实际用于本次评审：`minecraft-modding`核对锁定NeoForge/Create能力与方块生命周期，`minecraft-testing`划定新增结构的守恒/兼容与客户端检查边界，`minecraft-resource-pack`核对模型几何。只读代理使用高速模型；未改功能文件、未运行构建/测试/游戏。外观方向参考[Create官方项目说明](https://github.com/Creators-of-Create/Create#readme)的可见机械组件组合和世界内交互；具体造型属于本项目建议，不声称是官方设计。

## 三种路线

| 路线 | 玩家布置 | 收益与代价 |
| :--- | :--- | :--- |
| 保留单格并重做模型 | 单格机身，一只漏斗合并两粉输出 | 最快，旧存档改动少；合理布置后左右同样能留空，但造型空间较紧 |
| **推荐：宽1×深1×高2，一件放出上下两格** | 一件离心机直接放出完整立式机器，无需另外搭壳 | 占地仍一格，能表现转鼓与底座，左右紧贴成排；需要成对放置/拆除和旧机迁移 |
| 玩家拼装大型多方块 | 转鼓、机壳、控制/物料口分开搭建 | 可规划共享接口，但必须另定尺寸、成本、规模与吞吐关系，实现和验收范围明显扩大 |

推荐方案的接口如下。两格本身不减少物流通道；减少一条机器物品出口靠两粉合流，扩产靠统一朝向与公共管线。

| 位置 | 功能 |
| :--- | :--- |
| 下段底面 | 唯一动力输入，延续底部传动 |
| 下段背面 | 料浆输入，保留手工桶操作及抽回未处理料浆 |
| 整机顶部 | 回收水输出 |
| 下段正面 | 一个物品接口暴露两种粉；漏斗抽到公共产物线，末端分拣；保留空手收粉和停转轴承维修 |
| 左右两侧 | 不要求接物流或动力，留给相邻机器 |

两种流体采用后下与顶部的分离布置，避免把进浆、排水做成背面紧邻的上下接口，导致普通管道自动连成同一流体网。此稿不承诺任意相邻管线会自动隔离；接管与泵向仍按Create规则。成排机器可共用后方供浆线、上方回水线、前方产物线和下方传动网，最终密度与吞吐用短排代表场景检查。

## 推荐造型与交互

上部为八棱转鼓外壳，配上下金属箍、收口顶盖、窄观察窗；下部为较厚的轴承底座和可辨认的料口。使用灰色金属、少量黄铜紧固件和像素质感，让轮廓、接缝和运动部件承担细节。转子工作状态可通过可见转动表现，停机/堵塞由护目镜补充，不增设备面板。物品栏仍显示完整机器的立体缩略模型，手持使用合适的缩放。

这一外观方向和两格结构一并待确认；详细模型由资源执行者制作可查看预览后再交客户端验收，不以纯贴图替代几何变化。

## 建议兼容与验证范围

一件放置两格，空间不足不消耗物品或覆盖方块。下段持有唯一库存、批次、磨损；上段接口转交同一状态。拆任一半只回收整机一次，另一半随之移除，不能复制库存/机器。无论暂停、断电或读档，两半都不各自加工。

旧单格实例不自动覆盖上方方块；建议保留原物料、批次和磨损，提示用扳手收起后重新放置为两格设备，迁移前暂停加工。历史面过滤字段忽略，不把已经移除的规则继续作用在物流上。此迁移行为属于结构方案的一部分，随本稿待确认。

确认后再生成精确实现卡。自动只检查受影响的成对放置/拆除、共享状态/守恒、旧快照兼容与一次增量打包；不重复既有配方和速度/磨损整套用例。客户端集中检查新外观、短排产线的一批实际合流出料与独立进排液、任一半拆放及旧机迁移，不要求重测已通过的整套离心流程。
