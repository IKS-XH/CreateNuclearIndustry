## 1. 文档边界

本文只规定首发内容的 **输入材料、加工设备与输出材料**，用于确认科技树、材料闭环和自动化路线。以下数值均不在本稿冻结：

- 每次配方的物品数量与流体量；
- 加工时间、最低转速、应力消耗与加热等级；
- 副产物数量、产出概率与材料回收率；
- 多方块结构的方块消耗量；
- 燃料寿命、冷却时间与设备耐久。

后续平衡只能调整这些数值，不应随意改变本文确定的材料依赖关系。配方应优先使用 Create 原生加工类型；只有富集、烧结、屏蔽拆解、再处理等无法由原版设备清楚表达的步骤才增加专用设备。

本文不包含 FE/RF 发电、多种反应堆、聚变、反物质、航空学兼容专用部件或脱离 Create 后的替代配方。

实施时把“燃料状态合同”和“完整生存生产线”分开排程：先冻结 `fresh_fuel_assembly`（玩家名称“浓缩铀燃料组件”）与 `cooled_spent_fuel_assembly`（玩家名称“枯竭铀燃料组件”）的数据组件，使反应堆运行、存档和换料能够使用真实物品语义；`hot_spent_fuel_assembly` 注册 ID 保留为未来兼容位，首发运行不生成、不依赖。燃料耗尽直接得到冷却乏燃料；热/冷转换、乏燃料池冷却及相关玩法后置。随后再完成本文件第 5～8 节的全部获取路径。只有前者完成不能视为燃料制造阶段可玩。

G1/G2 可以先使用开发可获得的正式模组内容身份。当前占位 PNG 暂时挪用原版素材：煤炭→浓缩铀燃料组件、木炭→枯竭铀燃料组件、熔岩→热复合冷却剂、水→复合冷却剂；这些原版物品/流体不是配方输入、燃料别名或流体能力的合法替代品。接口与任务以 [G1/G2 决策包](./superpowers/plans/2026-08-17-g1-g2-decision-package.md) 和 [Agent 任务分派计划](./superpowers/plans/2026-08-17-g1-g2-agent-handoff-plan.md) 为准。

## 2. 配方表示与通用规则

### 2.1 表格约定

| 字段 | 含义 |
| :--- | :--- |
| 输入 | 必须投入的物品、流体或半成品；同一格内使用 `+` 表示共同输入 |
| 设备/工序 | 执行加工的 Create 设备、工作台或本模组专用设备 |
| 主输出 | 推进主生产链的确定产物 |
| 副产物/返还物 | 可回收材料或废物；具体数量和概率留待平衡 |
| 阶段 | 勘探、燃料制造、实验堆、商用机组或高级核能 |

### 2.2 标签与替代材料

- NeoForge 1.21.1 使用 **数据包物品标签**实现材料归类与跨模组兼容，不实现或依赖旧版 Ore Dictionary（矿物辞典）API。生态通用标签使用 `c:*` 命名空间，不再沿用旧版 `forge:*` 通用标签约定。
- 本模组新增的通用原材料与中间产物必须加入对应的 `c:*` 标签；配方输入必须引用标签，不得写死本模组物品 ID。其他模组只要将等价物品加入相同标签，就能直接替代本模组材料。
- 配方输出仍生成本模组的标准产物，除非配方类型原生支持统一产出选择；这能避免同一标签中存在多个候选物品时产物不确定。
- Create 原生的铁片、黄铜片、铜片、精密构件、安山合金、坚固板、流体储罐、机械泵、阀门、显示链接和烈焰人燃烧室保持原配方，不在本文重复定义。
- “耐热玻璃”“合金钢”“强化合金钢”等为本模组中间材料；最终注册名称可调整，但材料关系不得改变。
- 机器外壳配方可以由工作台或机械装配实现；量产路线应始终支持传送带、机械手和序列装配自动化。

### 2.3 NeoForge 通用标签目录

铅、铀和锡的每种标准形态均按相同规则注册。下表用 `<material>` 表示 `lead`、`uranium` 或 `tin`。若首发实际没有某种形态，则不为它创建空物品，但一旦加入就必须使用对应标签。

| 材料形态 | 必须加入/引用的标签 | 示例 |
| :--- | :--- | :--- |
| 普通与深层矿石 | `c:ores/<material>` | `c:ores/lead` |
| 粗矿 | `c:raw_materials/<material>` | `c:raw_materials/tin` |
| 粗矿块 | `c:storage_blocks/raw_<material>` | `c:storage_blocks/raw_uranium` |
| 锭 | `c:ingots/<material>` | `c:ingots/lead` |
| 粒 | `c:nuggets/<material>` | `c:nuggets/tin` |
| 粉 | `c:dusts/<material>` | `c:dusts/uranium` |
| 板 | `c:plates/<material>` | `c:plates/lead` |
| 线 | `c:wires/<material>` | `c:wires/tin` |
| 棒/杆 | `c:rods/<material>` | `c:rods/lead` |
| 金属储存块 | `c:storage_blocks/<material>` | `c:storage_blocks/tin` |
| 粉碎粗矿 | `c:crushed_raw_materials/<material>`；同时加入 Create 的粉碎原料集合标签 `create:crushed_raw_materials` | `c:crushed_raw_materials/uranium` |

本模组合金和通用加工材料采用相同的层级式命名：

| 材料 | 必须提供的标签 |
| :--- | :--- |
| 合金钢 | `c:ingots/steel`、`c:plates/steel`、`c:rods/steel`、`c:storage_blocks/steel`；优先兼容生态中已有钢材 |
| 强化合金钢 | `c:plates/reinforced_steel`；若无公认生态含义，不得冒充普通钢板 |
| 锡合金焊料 | `c:ingots/solder` 或生态已采用的等价焊料标签；同时提供本模组别名标签 |
| 石英粉、煤粉、木炭粉、黑曜石粉 | 分别使用 `c:dusts/quartz`、`c:dusts/coal`、`c:dusts/charcoal`、`c:dusts/obsidian` |
| 玻璃碎料 | `c:dusts/glass` |
| 工业陶瓷、耐火砖、隔热板、中子吸收陶瓷 | 使用本模组公共标签 `create_nuclear_industry:<形态或类别>`；没有公认语义时不得占用 `c:*` 通用命名空间 |

### 2.4 标签使用边界

- 矿物加工、压板、制线、合金混合和机器部件配方的输入全部使用标签。例如铅屏蔽桶读取 `c:plates/lead`，不得只接受本模组铅板。
- 本模组生成的矿石、粗矿、锭、粒、粉、板、线、棒和储存块必须反向写入相应标签，使其他模组的机器也能识别和加工它们。
- 矿石熔炼、粉碎、洗涤和压片配方要为标签中的等价输入提供相同路线；不得只给本模组矿石提供高产 Create 加工，而让其他模组同类矿石只能熔炼。
- 标签文件使用 `replace: false`，只追加本模组条目，不覆盖其他模组已经注册的材料。可选兼容条目必须使用 NeoForge 支持的可选标签条目，缺少目标模组时不能导致数据包加载失败。
- 数据生成测试必须检查标签成员、配方标签输入以及所有本模组通用材料形态，防止新增了物品却忘记加入标签。
- 复合冷却剂、受污染冷却剂和蒸汽属于流体，应使用适用的 `c:*` 流体标签或本模组流体标签，不加入物品矿物标签。
- 低浓缩铀粉、贫化铀粉、燃料芯块、燃料棒、燃料组件、乏燃料和高放残渣具有不同安全与燃耗语义，不能统统加入 `c:dusts/uranium` 或其他普通铀标签。它们使用本模组命名空间下的专用标签，防止其他模组配方绕过富集、屏蔽或废物处理流程。

## 3. 首发材料总关系

```text
铅矿 ─→ 铅锭 ─→ 铅板 ─┬→ 辐射屏蔽、屏蔽玻璃、乏燃料桶
                       └→ 屏蔽机器与热室部件

锡矿 ─→ 锡锭 ─┬→ 锡片/锡条 ─→ 仪表、密封、焊接与控制部件
               └→ 锡合金焊料 ─→ 燃料棒封端和耐压部件

铀矿 ─→ 铀精矿 ─→ 铀料浆 ─→ 低浓缩铀粉 ─→ 燃料芯块 ─→ 燃料棒 ─→ 燃料组件
                           └→ 贫化铀 ─→ 配重、屏蔽、再生燃料

铁/碳 ─→ 合金钢 ─→ 钢板/钢管/钢构件 ─→ 反应堆、锅炉、管道、汽轮机

青金石粉 + 红石粉 + 原版荧石粉 + 水 ─→ 复合冷却剂

乏燃料 ─→ 冷却 ─┬→ 灌封与铅桶封存
                  └→ 再处理 ─→ 再生燃料 + 回收包壳 + 高放残渣
```

## 4. 加工设备清单

### 4.1 复用 Create 的设备

| 设备/工序 | 在本模组中的用途 |
| :--- | :--- |
| 粉碎轮 | 破碎铅、锡、铀矿石，粉碎青金石，处理玻璃原料 |
| 磨石 | 小规模制粉和早期手工替代路线；效率低于粉碎轮 |
| 鼓风机洗涤 | 清洗粉碎矿、分离铀精矿与尾矿 |
| 鼓风机加热 | 烘干、预热和普通热加工；不能替代核燃料烧结炉 |
| 动力搅拌盆 | 混合合金、冷却剂、料浆、混凝土与灌封材料 |
| 压片机 | 制作金属板、燃料生芯块、密封环和桶壳 |
| 切石机 | 制作管材、叶片毛坯、结构框架和陶瓷内衬 |
| 机械手 | 插入包壳、封端、装配燃料棒和结构组件 |
| 序列装配 | 制作燃料组件、控制棒、仪表、阀门、汽轮机转子等复杂部件 |
| 工作台 | 少量基础方块与非量产应急配方 |

### 4.2 首发新增专用设备

| 设备 | 输入能力 | 输出能力 | 不能被替代的原因 |
| :--- | :--- | :--- | :--- |
| 富集离心机 | 铀料浆 | 低浓缩铀粉、贫化铀 | 需要稳定转速并同时产生两类核材料 |
| 燃料烧结炉 | 生燃料芯块、热源 | 烧结燃料芯块 | 需要密闭高温处理，普通鼓风加热不足 |
| 屏蔽装配台 | 放射性部件、包壳与结构件 | 燃料棒、燃料组件、屏蔽容器 | 防止玩家徒手批量操作高辐射物品 |
| 冷却剂净化器 | 受污染冷却剂、过滤介质 | 可复用冷却剂、放射性滤芯 | 必须把回收工质与固体废物同时结算 |
| 屏蔽拆解机 | 冷却乏燃料组件 | 乏燃料棒、受污染包壳 | 乏燃料不能用普通机械手安全拆解 |
| 密闭再处理器 | 乏燃料、处理介质、冷却剂 | 再生燃料粉末、高放残渣 | 保证燃料回收必然伴随高放废物 |
| 屏蔽热室 | 高放残渣、玻璃基材或待灌封废物 | 玻璃固化体、灌封废物件 | 隔离高温与高辐射加工 |

## 16. 配方完整性约束

1. **首发可达：** 从原版与 Create 可获得材料出发，玩家无需安装第三方材料模组即可完成所有首发生产链。
2. **Create 主导：** 除列出的专用核工业设备外，制粉、洗涤、混合、压片和装配均由 Create 设备完成。
3. **无物质删除：** 铀尾矿、受污染冷却剂、放射性滤芯、乏燃料和高放残渣都必须有明确去向。
4. **无燃料永动：** 再生燃料必须掺入新燃料原料，并始终产生不可回到同一闭环的高放废物。
5. **无热量复制：** 复合冷却剂状态转换、超临界汽轮机做功、换热器冷凝回水和 Create 锅炉支线不得重复生成流体或应力。蒸汽供热模式永远是普通热源品质，即使叠加热值也不能让高压锅炉重新产生超临界蒸汽。
6. **可自动化：** 所有量产步骤都有传送带、机械手、管道或专用屏蔽机械臂接口；反应堆在线换料是例外受控端点，只允许人工或 Create 动力机械臂逐列操作。
7. **危险分级：** 原矿和新燃料允许低强度防护；乏燃料、高放残渣和受污染工质必须使用屏蔽设备。
8. **数值后置：** 本文只冻结依赖图。数量、时间、转速、应力、概率和结构成本在原型平衡阶段统一填写。

## 17. 后续数值平衡需要补充的字段

后续平衡版本应为每条配方增加以下字段，但不得在缺少原型数据时凭经验随意填写：

| 字段 | 用途 |
| :--- | :--- |
| 输入/输出数量 | 确定材料成本和矿物需求 |
| 流体量 | 确定泵、储罐和管网规模 |
| 加工时间 | 确定生产线吞吐量 |
| 最低/最佳转速 | 确定 Create 传动设计 |
