# P1-REFUEL-02A 验收归档：换料端口燃料所有权

**验收日期：** 2026-09-06
**状态：** 已完成

## 验收结论

每个 `reactor_refueling_port` 已成为其绑定燃料列完整燃料 `ItemStack` 的唯一持久化所有者。仪表端口继续唯一持有热工、完整度、燃耗余量、冷却剂、控制棒、SCRAM 和融毁状态，只在正式 tick 中读取端口物品形成瞬时投影。

仪表快照格式升级至 v4，不再持久化第二份燃料组件；v0～v3 的旧镜像会幂等迁移到空端口，端口已有物品时以端口为权威。正式 tick 在写入前重新校验全部端口，任一端口或物品变化都会取消整次提交。护目镜可显示端口本地组件的剩余/最大耐久和比例，结构失效时不会显示陈旧热工数据。
