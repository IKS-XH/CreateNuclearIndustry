# P1-REPAIR-01 验收归档：燃料列钢板维修

**验收日期：** 2026-09-06
**状态：** 已完成

## 验收结论

玩家可用正式注册物品 `steel_plate` 右键绑定燃料列的换料端口进行维修。目标列必须停止产生新生裂变热；每块钢板恢复 `0.25 / internalHeight`，结果封顶到 `1.0`。

维修只修改目标燃料列完整度，不补充燃料耐久，不清除缓存余热、燃耗余量或量化热量余数，也不回退融毁进度。满完整度、错误物品、物品不足和仍放热场景均拒绝且不消耗材料。
