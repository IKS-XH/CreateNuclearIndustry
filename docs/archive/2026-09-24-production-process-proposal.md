## 1. 在已有可选工序中安排的分工

| 工序 | PM 任务设计安排 | 后续必须验证 |
| :--- | :--- | :--- |
| 钢板加工密封环、钢网和燃料包壳 | 密封环走压片；钢网、包壳选用原策划已允许的切石机路线，通过选定产物区分；不把三种产物写成同输入的竞争压片配方 | 实际产物选择、每次消耗、批量和保存；如利用 Create 锯床兼容石切，单独验证过滤器与相关配置关闭后的原版石切可达性 |
| 首台设备依赖的零件 | 重型轴承、工业陶瓷等先于实际消费它们的首台设备提供；不从表格中的阶段名反推核设备启动循环 | 从原版/Create 出发的完整物料图；不顺带提前辐射或后期事故系统 |
| 通用材料兼容 | 继续使用具体 `c:*` 材料标签并显式汇入需要的父标签；材料身份和产物注册另行核实 | 真实加载和配方匹配，追加不覆盖；不把标签模拟验收称为第三方整包联调 |

以上不批准新数量、处理时间或设备代码，只为后续任务选定既有方案中的明确表达。

## 2. D-03d 已确认的工序取舍

| 问题 | 用户已确认的方案 | 对玩家及实现的影响 |
| :--- | :--- | :--- |
| 煤/木炭磨石制粉会与 Create 染料竞争 | 与青金石分工一致：粉碎轮生产煤粉/木炭粉，磨石完整保留 Create 原配方；两者都产黑色染料并有概率副产灰色染料 | 制钢也需要粉碎轮；避免相同磨石输入随机选择产物。需测试粉碎轮专用配方优先及回退，不依赖遍历顺序 |
| 铀洗矿表中的“+水”含义不明确 | 采用现有 Create 鼓风机洗涤：水是加工环境，不按批扣 mB；铀料浆、冷却剂中的水仍按配方实际消耗 | 不为洗矿另造耗水设备；仍必须完整保留铀精矿和尾矿，验证实际洗涤行为与配方产物 |
| 耐火砖和工业陶瓷两个输入不能表达为普通单件压片 | 隔热板采用压片机配合工作盆的压实配方，保留两项原料 | 玩家需工作盆；具体热级、数量和是否满足实际配方类型还须任务验证，不改成只消耗一种输入 |

用户对上述三项成组确认问题答复“是”，本组工序决策等待已解除。PM 已同步 `recipes.md`；数量、产率、时间、热级以及 P1 交接等其余前置没有因此通过，不把需求确认写成实现或运行验收完成。
