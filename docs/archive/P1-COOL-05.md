## 1. 验收结论

反应堆失效、仪表端口替换或区块重载后，保持原位的冷/热端口与既有 Create 储罐、动力泵和管道能够自动恢复输入输出。恢复不要求玩家替换端口、拆装管道、再次扳手重扫或重复成型。

旧仪表所有者会在失效或卸载时释放端口；合法的新仪表端口能够接管陈旧绑定。旧 `IFluidHandler` 即使仍被外部缓存持有，也会通过世界方块实体身份、所有者生命周期和结构有效性校验失去写入能力。有效绑定边沿会刷新 NeoForge capability，并通过 Create 6.0.10 的公开流体传播入口使相邻管网重新发现端点。
