# P1-REFUEL-02B 验收归档：未成型端口安全取料

**验收日期：** 2026-09-06
**状态：** 已完成

## 验收结论

未成型且未绑定的换料端口在服务端确认旧反应堆状态安全时，允许玩家空手取回端口中的精确燃料 `ItemStack`。交互只取不放，不暴露普通 `ItemHandler`，不会向漏斗或 Create 机械臂开放绕过入口。

运行、融毁倒计时、暂停倒计时或无法证明安全时，端口以持久化 `UnformedExtractionAllowed` 锁拒绝取料。缺少该字段的旧 NBT 默认拒绝；区块卸载不解锁，只有重新绑定并由服务端确认安全后才重新计算许可。
