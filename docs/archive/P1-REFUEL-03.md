## 验收结论

换料端口已注册专用 Create `ArmInteractionPoint`。机械臂只识别有效绑定端口和合法燃料，通过既有换料事务完成单件放入或取出，不向通用物品物流暴露能力。

`simulate=true` 全程只读，`simulate=false` 才提交；预检后结构、端口或物品变化会拒绝操作。正式提交同时更新端口唯一燃料物品和仪表端口瞬时模拟投影，异常时回滚，不能复制、吞掉燃料或绕过停止放热条件。
