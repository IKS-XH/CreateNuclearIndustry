## 2. 任务交接模板

每个任务必须明确以下字段：

| 字段 | 要求 |
| :--- | :--- |

### P1.2-DAMAGE-01 燃料列/控制棒列损伤、传播与修复合同

- **目标：** 在多方块结构服务端状态中为每个燃料列独立持久化并实现 `fuelColumnIntegrity`，为每个控制棒列持久化 `controlRodColumnIntegrity`，实现有效热负荷损伤、同比发热/燃耗反馈、失效传播、控制棒卡死、融毁倒计时和燃料列修复路径。
- **前置：** `P1.2-SIM-01`、`P1.2-COOLANT-01`，以及用户确认燃料列损伤方案。
- **必须覆盖：** 每列独立保存和结算；燃料列损伤只来自累计有效热负荷；冷却足够时超频不降低完整度；热负荷越高完整度下降越快；完整度越低发热和燃耗按相同比例增加；完整度归零后燃料列停止发热/燃耗但按当前余热执行四向传播；控制棒列归零后卡死但不传播；传播热量被目标列冷却带走时阻止；当前传播热量覆盖默认 20% 有效燃料列后进入持久化 `meltdownCountdown`；损伤与燃料 ItemStack 耐久分离。
- **修复边界：** 冷却充足只停止新的损伤，不自动修复完整度；燃料列使用 1 块 `alloy_steel_plate` 右键换料端口、且列停止放热时恢复 `0.25 / internalHeight`；控制棒列使用同一钢板右键 `control_rod_drive`。维修不补燃料、不解锁控制棒、不回退融毁进度；全部燃料列和控制棒列修复到完整后才重置融毁状态。完全停机重组成型是另一个破坏性重置任务。
- **待确认：** 仅剩数值原型的热负荷单位/阈值、传播系数和倒计时长度；玩法语义、维修物品、修复比例、传播方向、20% 口径和融毁重置条件已冻结。
- **验收：** 纯模拟测试覆盖逐列独立损伤、冷却充足超频不损伤、同比发热/燃耗反馈、零完整度停止热/燃耗、现场热量传播无标记、控制棒卡死、20% 阈值、存档/重载、快照顺序无关、倒计时暂停不回退、全列修复重置；GameTest 覆盖护目镜读数、合金钢板维修、换料拒绝、热量被冷却阻断、失效列传播和倒计时持久化。

### P1.2-MAINT-01 停机重组成型与结构破坏规则

- **目标：** 实现完全停机后的破坏性维护重置，以及运行中拆除组件的即时融毁倒计时。
- **前置：** `P1.2-DAMAGE-01`、结构状态持久化和 SCRAM 状态机。
- **完全停机条件：** 反应堆没有有效裂变产热或燃料消耗，余热已降到安全区，且没有正在运行或暂停中的融毁倒计时；仅插入控制棒、仅 SCRAM 或仅暂停倒计时，不视为允许重置。
- **重置行为：** 完全停机后重新成型清空该多方块结构全部内部 NBT，包括内部燃料组件、冷/热冷却剂、每根控制棒目标深度、燃料列缓存热量、燃料列/控制棒列完整度和融毁进度；内容永久丢失，不自动返还。
- **事故行为：** 反应堆运行、融毁倒计时或暂停融毁倒计时期间拆除任意结构组件，立即将倒计时归零并执行融毁动作，喷出热复合冷却剂和高放射性废物；组件补回、结构重新成型或普通冷却不得回退已经发生的融毁动作。
- **验收：** GameTest 覆盖余热安全区、完全停机重组成型的全 NBT 清空、运行/倒计时/暂停三种状态拆壳拆端口拆燃料列的即时融毁动作、重装不能回退进度、SCRAM 不能绕过重置条件。

### 2026-08-17：确认燃料列独立热负荷损伤与融毁传播（历史草案，已由 2026-08-18 决策修订）

- 每个燃料列的 `fuelColumnIntegrity` 是多方块结构服务端状态中的独立持久化变量，不写入燃料组件 ItemStack；每个燃料列独立计算完整度、有效热负荷和当前发热量。
- 完整度下降只由该列累计有效热负荷决定。超频只提高发热，不是独立损伤源；冷却剂足以带走该列热量时，即使超频也不会降低完整度；热负荷越高，完整度下降越快。
- 完整度越低，该列发热量越大，并设置配置上限，形成可预测的热失控正反馈；冷却充足只停止继续损伤，不自动修复完整度。
- 完整度归零后，失效列沿燃料列邻接关系向其他有效燃料列传播损伤，传播持续到满足全堆融毁触发条件并进入服务端持久化融毁倒计时。
- P1.2-DAMAGE-01 必须新增逐列热负荷、完整度—发热反馈、存档重载、传播快照、融毁触发/倒计时测试；传播拓扑、速率、融毁中止条件和修复路径仍需单独确认后才能冻结数值。

### 2026-08-18：确认控制棒卡死、20% 融毁阈值与破坏性维护

- 损伤传播只沿水平北、南、东、西四向相邻关系传播。燃料列归零后停止发热和燃料消耗，但按当前缓存/余热现场传播热量；控制棒列接收同样的相邻热量，完整度归零后控制棒卡死，保持卡死前插入比例继续抑制相邻燃料列，且不向外传播热量。
- 完整度损失百分比同时等比例增加该燃料列发热和燃料消耗；完整度归零时两者均为零。传播触达暂定 `20%` 的有效燃料列时建立融毁倒计时，控制棒列不计入比例。
- 融毁倒计时期间，SCRAM 和有效冷却可以暂停计时，但不能回退融毁进度或恢复完整度；只有所有燃料列和控制棒列修复到完整后才重置融毁状态，危险条件恢复时从原进度继续。
- 受损燃料列使用 1 块 `alloy_steel_plate` 右键换料端口修复，维修前目标燃料列必须停止放热；每次恢复 `0.25 / internalHeight`。控制棒列用同一合金钢板右键 `control_rod_drive` 修复。
- 完全停机且余热进入安全区后允许重新成型反应堆，这会永久清空整个多方块结构的内部 NBT，包括燃料组件、冷/热冷却剂、控制棒深度、燃料列缓存热量、列完整度和融毁进度；运行、融毁倒计时或暂停融毁倒计时期间拆除任意结构组件直接执行融毁动作，重装不能回退进度。
