# 汽轮机01C：从空地开始的合并复测

**状态：候选已构建并通过定向验证，等待本表的客户端手测。** 请关闭旧客户端后从下述目录重新启动。本表合并01B遗留视觉门和01C搭建整改，不另跑旧清单。

启动目录仍为同级候选：

```powershell
cd E:\MyMC\NewMod\Create_NuclearIndustry-ore-acquisition
.\gradlew.bat runClient
```

尺寸为宽×轴长×高：小型3×5×3（3转子），中型5×8×5（6转子），大型7×11×7（9转子）；两端各1动力轴。256RPM与已批准性能、原配方/用量不变。配置有自定义时以实际配置为准。

本轮主要检查新增搭建过程，旧热端/材料不复测。推荐小型走完整流程，中/大型只核对轴列定位、壳体截面和转子大小。

| 检查 | 操作与预期 |
| :--- | :--- |
| 独立板与扳手 | 单独在不同面放外壳/窗，扳手调整；选框、碰撞与实际板面重合，不能板在上而选框在下 |
| 轴列先行 | 先放两端轴和连续转子，不放控制器/壳体；应能辨认轴向，完整轴列确定档位后显示对应叶轮；此时不能运行或处理蒸汽 |
| 逐块包壳 | 手持外壳对转子看预览并右击补一块，对已有壳沿轴延伸，对两端轴补端盖；生存一次扣一件，失败不扣、不覆盖障碍，潜行可普通摆放；半圈/缺件也应显示正确平面和斜角 |
| 接口、窗口与成型 | 按下述已批准位置补接口，观察窗替换合法平直壳；控制器提示缺件并标出位置。补齐才运行，窗口内能看见叶轮，手持/物品外观正常 |
| 运行、拆件与复原 | 接入超临界蒸汽，双端动力仍按256RPM及份额工作，排出蒸汽；拆一壳停机且其余形状不散成横板，补回恢复。控制器/流体库存不能因外观更新丢失或增加 |
| 规模与保存 | 中/大型至少看到正确宽度、轴长、拐角和叶轮，不要只把小型拉长；保存重进后保持。邻近两台机器不串接壳/库存/模型 |

接口位置沿用01B，轴向从前端轴所在排记为z=0：

- 四侧平直面的中央区：恰好1控制器、至少1进汽口；小型z=2，中型z=3/4，大型z=5。
- 四侧平直面的两端区：至少1排汽口，z=1或z=L−2。
- 两个轴向端面中心为动力轴；剩余端面封闭。观察窗只替换中段四侧平直中心壳位。

发生问题时记录“当时搭到哪一步、哪一档、朝向、手持物品及缺件提示”，截图尽量同时显示轴列和操作位置；无需为了提供反馈重跑整份清单。
