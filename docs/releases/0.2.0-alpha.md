# Create: Nuclear Industry 0.2.0 Alpha

For **Minecraft 1.21.1 / NeoForge**.

## What's new

- Radiation now affects non-player living entities. They accumulate dose, suffer symptoms and damage, and recover when exposure falls.
- Create's hose pulley can treat connected uranium slurry pools as bottomless. Create's default threshold is 10,000 connected fluid blocks. Contact with source or flowing slurry applies Poison I.
- Wrench an empty Shielded Assembly Station to switch between Assembly / Sealing and Disassembly. Engineer's Goggles show the selected mode. Disassembling an exhausted fuel assembly returns 4 steel plates, 9 tin nuggets, 3 lead nuggets, and 1 spent fuel residue. Seal the residue in a lead cask for dry storage.
- The **Create: Nuclear Industry** category in Create's Ponder Index provides ten equipment entries covering all 25 scenes.

## Installation

Use Minecraft 1.21.1, Java 21, NeoForge 21.1.219, Create 6.0.10-280 and the dependencies required by Create. Install `create_nuclear_industry-0.2.0-neoforge-1.21.1.jar` in `mods` on both client and server. JEI is optional. The attached `SHA256SUMS.txt` identifies this build.

This is an Alpha. Back up your world before upgrading. The radiation system reads the station's inventory while the station is placed in the world. Inventory carried inside a picked-up station is outside that scan. Report issues with the mod and loader versions, reproduction steps, and relevant logs. [GitHub Issues](https://github.com/IKS-XH/CreateNuclearIndustry/issues)
