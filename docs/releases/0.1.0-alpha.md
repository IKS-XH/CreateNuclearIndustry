# Create: Nuclear Industry 0.1.0 Alpha

First public Alpha for **Minecraft 1.21.1 / NeoForge**.

Build a nuclear industry around Create: process uranium, manufacture fuel, configure a reactor core, move heat through coolant loops, produce steam and drive the Create stress network.

## Included

- Uranium processing, enrichment, fuel sintering and assembly; depleted-uranium materials and equipment.
- Configurable reactors from 5 to 16 blocks per side, fuel columns, control rods and coolant ports.
- A Blaze Burner reactor administrator with a three-page interface, manual control, constant heat output, safety protection and save/resume continuity.
- Heat exchangers for Create boilers, basins and fuel sintering furnaces; variable-size high-pressure boilers, three turbine sizes and steam condensation.
- Dedicated industrial pipes, valves and a mechanical pump for coolant and supercritical steam.
- Radiation, protective clothing, a radiation meter, shielded waste containers and dry storage racks.
- Local reactor accidents, hot debris and cooling molten corium; boiler dry-firing and overpressure accidents.
- **25 Ponder scenes** covering equipment use, administrator setup, accident handling and radiation protection.

## Installation

| Requirement | Tested baseline |
| --- | --- |
| Minecraft Java Edition | 1.21.1 |
| Java | 21 |
| NeoForge | 21.1.219 |
| Create for NeoForge | 6.0.10-280 |

Install Create and the dependencies required by its distribution. Place the attached `create_nuclear_industry-0.1.0-neoforge-1.21.1.jar` in `mods`. Install the same versions on the client and dedicated server. JEI is optional and useful for recipe lookup. Use the in-game Ponder tutorials to learn the equipment.

The attached SHA-256 file identifies this exact JAR. GitHub's automatic source-code ZIP/TAR files are source archives, not installable mods.

## Alpha status

Back up worlds before use. Balance, configuration and save formats may change. Individual equipment and tutorial batches have passed their reported manual tests; extended end-to-end survival, large multiplayer installations and every shader/modpack combination are not fully verified. Industrial transport currently models flow, not pipe pressure. Complex fuel reprocessing and plant-wide automatic coordination are not included.

The release build has **860 passing JUnit tests, no failures, and 11 existing Sodium fixture tests skipped** because their dedicated fixture directory is not configured. This does not replace client or multiplayer testing.
