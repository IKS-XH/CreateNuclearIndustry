# AUDIO-CENTRIFUGE-01：离心机首个试听小样

用户在“制作音效”对话确认首样方向，并授权该对话向主PM提交工作树/写集申请；PM核实用户原文后按本卡安排。此卡仅首样素材，不授游戏接入或其它设备实现权限。

## 交付与写集

- 工作树/角色入口见[音效README](../README.md)。音效负责人可维护`docs/audio/README.md`、本卡及`docs/audio/reports/AUDIO-CENTRIFUGE-01.md`；具体素材/合成实现交给限定执行者。
- 执行者唯一素材/程序写目录：`tools/audio-assets/centrifuge-01/`，包含WAV、可编辑程序合成源、固定参数、格式/峰值/接缝检查结果和原创MIT声明；交付报告允许写`docs/audio/reports/AUDIO-CENTRIFUGE-01.md`。
- 约6～8秒平滑循环音，加短淡入/淡出组成启停试听片段。低音量、中低频机械转子质感，减少尖锐啸叫/持续高频嘶声，考虑Create KINETIC底噪；不制作其它设备、报警或完成提示。
- 已知Python/NumPy/wave可用；OGG编码器未确认，允许先交WAV并报告限制。核实工具后再选编码方案，不下载/安装未经授权软件，不虚构听觉回传或试听能力。
- 原创素材/源文件MIT，第三方素材必须真实记录来源/许可，不改称原创。具体声道/采样率/响度由音效负责人在本卡内记录实际选择和理由；首样不构成最终游戏播放标准。

## 验证与权限

只验证格式、峰值、削波及循环接缝；实际长听是否刺耳、接缝/疲劳感由用户试听验收，二者分别记录。无需Minecraft构建/测试，不把波形检查称已通过听感。

禁止改Java、运行资源、共享语言、Gradle、核心治理/STATUS、正式JAR、用户世界或其它工具；执行者与音效负责人均无Git写/发布权限，不任命继任者，不实现新的游戏状态。来源和素材通过后交主PM按授权管理Git。
