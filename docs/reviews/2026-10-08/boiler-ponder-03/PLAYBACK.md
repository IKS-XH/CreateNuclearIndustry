| 情景 | 重点检查 |
| :--- | :--- |
| 搭建与分区 | 能看清底部换热器、中部再加热隔层和上下炉腔；热口与换热器同层、冷口与隔层同层；不同端口的合法位置、安全阀及多个端口说明清楚。 |
| 接通并运行 | 给水、热液输入和冷液回收始终可分辨，管路没有穿壳；水区/汽区缓存、升温和升压关系说明清楚。 |
| 蒸汽输出与调压 | 两种汽从各自选定端口进入独立管路，分别存汽、共用容量的含义清楚；压力下限不会被误解为目标炉压或安全阀阈值。 |
| 停机与排查 | 红石停止新收热、余热仍可产汽的过程清楚；缺水、堵塞和安全阀泄放的原因与处理能对应画面。 |
