# 0.2.0 生物辐射与铀料浆候选

候选分支 `codex/0.2.0-radiation-slurry`，构建来源 `413670414c0f3b87d4cdfe908e3e94c77287cf26`。当前供集中游戏验收。枯竭燃料回收另见[金属回收提案](../../../proposals/2026-11-25-spent-fuel-metal-recovery.md)。

- 服务端对实际 tick 的非玩家活体结算辐射。场强、实体屏蔽、穿戴减免、剂量恢复、症状和伤害沿用原有规则。非零剂量、恢复等待和伤害时钟随实体保存。玩家的创造与旁观待遇、告警、仪表和存储入口保持现行规则。
- 生物采样在玩家之后以每维度最多 4 次开工、4 次续接、16 个挂起任务运行。移动在限定距离与样本年龄内续接原采样，残缺样本不推进剂量及安全计时。高剂量伤害按实体 tick 继续。玩家占满该维度预算时生物采样可能延期。
- `create:bottomless/allow` 追加铀料浆源态与流动态。液池连通性、距离、门槛和白名单策略由 Create 处理，当前锁定版本的默认门槛为 10,000 格。
- 增量 `assemble` 成功。此版 JAR 保存在 `build/reports/radiation-slurry-20261125/create_nuclear_industry-0.2.0.jar`，为 3,792,418 字节，SHA-256 `8EE70D64C49256CBCE875C239F769DB5EAF92F079E69FFB0DF62732B03670D86`。

## 验证

30 项定向 JUnit 通过。移动续接整改后，隔离服务端最终 17/17，正常保存退出。其中包括无人同维环境下牛、尸壳及同批八只生物受照，屏蔽、距离和全套防护对照，撤离恢复至零，真实伤害、症状、实体 NBT，以及有限射线预算下跨格完成采样。真实 Create 软管滑轮在临时 4 格门槛下验证无限反复抽取和小池耗液，并恢复默认 10,000。万格游戏实景由下面的手测验证。

原始日志、范围核对与制品信息在同工作树的 `build/reports/radiation-slurry-20261125/`。采用 `minecraft-modding`、`minecraft-testing`、`minecraft-resource-pack` 和 `minecraft-ci-release` 核实注册、真实测试、标签及版本入口。

## 集中手测

1. 在同一测试区固定一只牛和一只敌对生物，在身旁放未封装的枯竭组件。观察生物累计高剂量后的迟缓、虚弱及掉血。再用屏蔽墙隔开或将它们移远，观察恢复。用创造玩家持辐射计核对场强，同时检查生存玩家仍按原规则受照。
2. 用软管滑轮分别抽小料浆池与能被 Create 搜索到 10,000 个连通料浆格的大池。小池持续抽取应减少源格，大池被识别为无限源后可持续抽取且不耗源格。自定义 Create 服务端配置按该服实际门槛和抽取范围核对。
