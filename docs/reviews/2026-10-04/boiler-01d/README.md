## 现行位置

从底部数第2层放给水口，第4层放蒸汽口，每侧三个非棱边位置均可使用，正面朝外。控制器仍占第2层某侧中央，因此该面可放2个给水口、其余侧各3个；整炉最多11个给水口、12个蒸汽口。水汽端口各至少1个，控制器和顶部中央安全阀各恰好1个。

每口独立最高256mB/t，水/汽各16000mB仍是全炉共享；同一口主动与被动传输共用其额度。产汽上限仍由热量和水量决定，九换热段最大162mB/t，多口不增产。旧中央口布局仍有效，无需重搭旧锅炉即可在允许位置换壳为口。

本轮也修正南北面偏移位置的外法线判断、端口反查控制器以及两层全部候选位置的能力失效/管面恢复；未改变账本、热量、安全阀、流体品质或配方。
