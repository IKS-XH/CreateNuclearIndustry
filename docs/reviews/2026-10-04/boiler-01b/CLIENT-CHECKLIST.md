## 新结构

锅炉本体5×5×5、内部3×3×3空气。棱边和角点全为外壳，观察窗只替换侧面非棱边普通外壳。图均为俯视，上背下前；K正面向外，W/S接口向外。

C外壳，H核换热段，K控制器，W给水口，S蒸汽口，V安全阀，点号为空气。以下为9段、单水口单汽口；需要少段时将不使用的H替换为C。

```text
第5层（顶）   第4层         第3层         第2层         第1层（底）
C C C C C     C C C C C     C C C C C     C C W C C     C C C C C
C C C C C     C . . . C     C . . . C     C . . . C     C H H H C
C C V C C     C . . . C     C . . . C     C . . . C     C H H H C
C C C C C     C . . . C     C . . . C     C . . . C     C H H H C
C C C C C     C C S C C     C C C C C     C C K C C     C C C C C
```

共85普通外壳＋9换热段＋K/W/S/V各1＝98个结构块。每个H下另放换热器，共9台；整机含热源高6格。阀门正上方一格留空气。多水口可占第2层其余侧面中央，排除K；多汽口可占第4层其他侧面中央。

下方九台换热器全部同向，每排三台紧贴，横向相邻的另两排不会合并。橙面热液入口，蓝面冷液出口，箭头同时指示流向；三排分别两端接管。以下箭头为冷却剂流向，热仍各自向上交付：

```text
热液 → [换热器][换热器][换热器] → 冷液
热液 → [换热器][换热器][换热器] → 冷液
热液 → [换热器][换热器][换热器] → 冷液
```

每排冷热容量各12000mB，护目镜展示整排共享量，不能把同排三台读数重复相加。满九段需实际供给162HU/t，默认热液转冷324mB/t；不足供给时低于额定是正常结果。暖炉满负荷约10秒，换热器启动延迟另计。锅炉水汽容量各16000mB、整炉输入/输出分别最高256mB/t。

## 仅复测三组

1. **外观、结构与减料。** 七种锅炉块与此前风格统一，外壳顶面左右/前后对称，观察窗可透视；换热器前后接口和箭头可区分，手持正常且无闪烁。新炉成型；把棱边替换为窗/热段应拒绝，恢复后重扫通过。JEI强化板为钢板→加入坚固板→压片，产1，不再需要精密构件。
2. **九段及无泵出汽。** 按三排接热液和返冷，中央机能工作，各排共享库存可见。水正常供给；汽口外向连接普通Create管道到储罐，去掉该蒸汽管路上的外部动力泵仍能主动出汽。短暂堵住接收端再恢复，应恢复输送，正常闭环冷热总量不变。旧侧/底混合管口已停用，须按新前后接口重接。
3. **拆接与存档。** 保存前记共享冷热总量，重进后核对。收起中间换热器，物品只携其自身库存份额，左右拆列各保留剩余量；重放并同向连接后总量仍相同且中央机恢复。旧3×3×4控制器库存应保留，重搭新结构并重扫后可继续用。
