## 一次顺序验收

| 检查 | 操作与预期 |
| :--- | :--- |
| 1. 制造 | 按下图搭21格动力合成器，投入10钢板、6金板、2重型轴承、1工业传感器、1搅拌器零件、1精密构件，恰好产1台富集离心机。中央使用`create:whisk`，不是完整动力搅拌器。 |
| 2. 原料 | 水洗8粉碎粗铀，恰得8精矿＋8尾矿；1尾矿压成1可放置的尾矿砖。8精矿＋1000mB水在普通加热的工作盆中搅拌成1000mB料浆；不加热不能完成。 |
| 3. 手工搬运 | 01A起按用户新决定使用原生料浆桶，允许世界倒出/舀回。以生存模式在Create储罐/工作盆与机器左口之间搬运料浆，整桶1000mB，满桶可能进入背包；从右口取回水。错误流体、空间不足或不足整桶时，两端均不丢量。创造模式的Create取液原生不返满桶，不用于此项守恒验收。 |
| 4. 一批加工 | 空机背面接128RPM动力，约1秒后护目镜应从“转速稳定中”变为“等待料浆”；装入1000mB料浆后有效加工约20秒，恰得1低浓缩铀粉＋7贫化铀粉＋1000mB水。面板与护目镜能读到数量、进度、转速、轴承和暂停原因。 |
| 5. 动力与恢复 | 下一批加工中断动力或使轴网过载，进度保留；恢复动力、改256RPM或反转后重新稳定约1秒再继续，256RPM整批有效加工约10秒。留一批未完成，记录两罐、两粉和进度，停机后用扳手取下再放置、保存退出重进，状态保留，完成后不重复产出。另用合适镐普通挖掘一次，机器内物料只随单件机器保留，无额外散落副本。 |
| 6. 自动化与堵塞 | 左口管道供料，右口排水，底部先用原版漏斗、再用Create漏斗各取到两种粉；产物槽不能反向插入。暂停排水，累计4批使水罐到4000mB后继续供料，机器显示堵塞且不消耗下一批；排水后恢复，无材料丢失。 |
| 7. 维护与展示 | 按下节近耗尽操作检验停机维修；JEI能查到制造、洗矿、制浆、尾矿压砖和离心分类，离心分类显示料浆、两粉、水及额定条件。检查新方块、四种新物品与料浆无紫黑缺图，机器接口图案与真实方向一致。 |

上述时间按正常20TPS，包含稳定等待的墙钟时间会稍长；原生制浆的`processing_time=200`不是固定10秒。两粉槽分别堵塞、小数转速磨损、交易模拟与失败不改量、批次快照等内部边界由定向自动测试覆盖，不要求手工重复整套组合。

## 轴承维修的短操作

只操作开启命令的测试世界中指定机器，将`<x> <y> <z>`换成实际机器坐标。停机后设置到距离耗尽只差一次256RPM有效推进：

```mcfunction
/data modify block <x> <y> <z> WearUnits set value 18874236928L
/data modify block <x> <y> <z> WearRemainder set value 0.0d
```

有料且输出畅通时接256RPM，稳定后一次有效推进即耗尽，机器暂停并保留批次。仍有转速时用重型轴承不能维修；停到0RPM后以生存模式从正面用1重型轴承恢复寿命，只消耗1件，批次和物料保留。耗尽时可顺便拆放一次，确认不能免费恢复轴承。不需要实际挂机两小时；这两个数值对应当前实现，勿用于已有正式存档里的生产机器。
