## 一次顺序验收

| 检查 | 操作与预期 |
| :--- | :--- |
| 1. 制造 | 按下图搭21格动力合成器，投入10钢板、6金板、2重型轴承、1工业传感器、1搅拌器零件、1精密构件，恰好产1台富集离心机。中央使用`create:whisk`，不是完整动力搅拌器。 |
| 2. 原料 | 水洗8粉碎粗铀，恰得8精矿＋8尾矿。按用户新比例，用机械压力机＋工作盆压尾矿：放3份不加工，补第4份后消耗4份并产1块可放置尾矿砖；8尾矿共压2砖，JEI显示4:1，原单件压片入口消失。8精矿＋1000mB水在普通加热的工作盆中搅拌成1000mB料浆；不加热不能完成。 |
| 3. 无GUI与过滤 | 四周和顶部各有可独立设置的Create原生过滤槽，底部没有；放料浆桶、水桶、两种粉和原生列表过滤器分别检查允许/拒绝，空手清空过滤恢复不筛选。点击过滤框外空手直接收取该面允许的粉，不开GUI；桶和重型轴承点击过滤框应设置过滤，不被直接搬运/维修抢占。数量/进度/转速/轴承/暂停原因由护目镜查看。 |
| 4. 桶与一批加工 | 生存模式从世界源/工作盆/储罐取料浆，桶身保持原版铁桶，仅内部显示料浆；原生工作盆满桶可能进入背包。把1000mB料浆放入设为料浆的机面，底部128RPM稳定约1秒后有效加工约20秒，恰得1低浓缩铀粉＋7贫化铀粉＋1000mB水；设水桶的面取水，错误流体、过滤拒绝、不足整桶/空间不足均不丢量或倒液到机器旁。创造模式原生不返桶，不用于守恒判断。 |
| 5. 动力与恢复 | 只有底部轴能驱动，侧面/顶部接轴不驱动。断动力/过载暂停保留进度；256RPM或反转后重新稳定约1秒，256RPM每批有效10秒。设置不同机面过滤并留一批未完成，记录两罐、两粉、进度与磨损；扳手取下再放置、普通镐拆放、保存退出重进后状态与过滤都保留，不复制产物或重置轴承。 |
| 6. 自动化与堵塞 | 对准非底面过滤框外普通右键可安装管道/漏斗，扳手可正常操作；接管后仍可点选面边角的过滤槽。用管道输入料浆/抽水、Create漏斗抽两粉；分别设置面过滤证明被拒物料无法通过，修改/清空后不用重接管线即可生效。底面不传物料，两粉槽不能反向插入；允许未加工料浆从匹配面抽回。停排水累计满4000mB后，机器堵塞且不消耗下一批；排水后恢复。顶部和四个侧面均检查至少一次接口或过滤操作。 |
| 7. 维护与展示 | 按下节近耗尽操作，停转后持1重型轴承点正面过滤框外完成维修；点击过滤框只设置过滤，不维修。JEI显示制造、洗矿、制浆、4:1尾矿压块与离心配方。检查精矿/新素材无紫黑、离心机物品栏立体/手持比例正常、底部轴承面及五面中性接口方向与实际一致。 |

## 轴承维修的短操作

只操作开启命令的测试世界中指定机器，将`<x> <y> <z>`换成实际机器坐标。停机后设置到距离耗尽只差一次256RPM有效推进：

```mcfunction
/data modify block <x> <y> <z> WearUnits set value 18874236928L
/data modify block <x> <y> <z> WearRemainder set value 0.0d
```

有料且输出畅通时接256RPM，稳定后一次有效推进即耗尽，机器暂停并保留批次。仍有转速时用重型轴承不能维修；停到0RPM后以生存模式从正面用1重型轴承恢复寿命，只消耗1件，批次和物料保留。耗尽时可顺便拆放一次，确认不能免费恢复轴承。不需要实际挂机两小时；这两个数值对应当前实现，勿用于已有正式存档里的生产机器。
