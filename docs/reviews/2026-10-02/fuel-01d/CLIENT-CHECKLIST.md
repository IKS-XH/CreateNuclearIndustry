整机占宽1×深1×高2。底部接轴；上段顶面进料浆。上下两段四个水平面均可接漏斗抽两粉、接管道抽水，具体位置由玩家选择；没有机身过滤槽。原生漏斗可以选择一条公共产物线再分拣。顶部可抽回未加工料浆，水和粉不能从顶部取；水平面不能灌料或塞入粉。不要让外部料浆总管和水总管相互连通。

## 一次增量检查

| 项目 | 操作与预期 |
| :--- | :--- |
| 1. 旧机升级与放置 | 原单格机保留物料、进度和磨损，暂停并显示重放提示，不覆盖上方已有方块。用扳手收起，再向上方有空间的位置放置，一件形成上下两格，原状态保留。上方被占时不能放置、不消耗机器；普通扳手调整方向后两半一致。 |
| 2. 接口和一批守恒 | 从顶部送1000mB料浆，底部128RPM加工一批；任意水平面用一只不设过滤的黄铜漏斗依次取出1低浓缩铀粉＋7贫化铀粉，另一水平面抽回1000mB水。再换到上段或别的侧面接管/漏斗，仍能访问同一库存；外置过滤正确，两侧同时抽取不复制。错误面/流体拒绝，不从侧面灌料；手工桶失败不丢量，空手水平面取粉不开GUI。 |
| 3. 小规模成排部署 | 三台左右紧贴，顶部公共供浆、侧面上下两层分别布置水线和产物线、底部统一传动。每台一批时总计3低浓缩铀粉＋21贫化铀粉＋3000mB水。任一台堵住产物口只暂停该机，疏通后恢复；相邻机不共享库存或重复加工。管网隔离和泵向按Create设置。 |
| 4. 拆放与恢复 | 留一台有库存/未完成批次，分别用镐挖上段、用潜行扳手拆上段；每次只回收一件带完整数据的机器，另一半消失，重放继续原状态。保存退出重进仍保留。另用空测试机检查创造拆上/下段无残壳，普通底段拆放同样只回收一次。 |
| 5. 外观与连接 | 检查八棱转鼓、顶口、金属箍、观察窗、底座和转子运动；停转/过载时停止。模型无紫黑、缺面/穿帮，上下接缝正常；四个朝向与相邻紧贴时不串模，接管/漏斗不遮死可操作区域。物品栏是完整立体机，第一/三人称手持大小合适，所有面无旧过滤框；护目镜与原轴承维修入口仍可用。 |

测试放置空间和拆放只用可回收的测试机器。保护插件或其他模组拦截放置的情形若无当前环境，不要求另装插件；其回滚策略由源码审查及可用定向验证单列。爆炸/替换等未实际验证边界不得记成人工通过。
