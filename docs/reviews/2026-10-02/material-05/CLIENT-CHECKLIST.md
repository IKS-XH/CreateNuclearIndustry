## 加工与数量

| 检查 | 操作 | 预期 |
| :--- | :--- | :--- |
| 磨石制粉 | 向磨石投入1下界石英 | 消耗1石英，得到1石英粉 |
| 粉碎轮制粉 | 向正常工作的粉碎轮投入1下界石英 | 同样得到1石英粉，无副产物 |
| 普通热制砖 | 工作盆放1砖块、1黏土球、1石英粉，动力搅拌器和正常燃烧的烈焰人燃烧室工作 | 恰好消耗各1件，产4耐火砖；不要求烈焰蛋糕 |
| 轴承装配 | 以1Create坚固板为基底，机械手依次放1钢锭、1精密构件，最后压片 | 逐步形成重型轴承半成品并显示原生进度，最终恰好1重型轴承 |

这里的砖块是4个红砖合成的`minecraft:bricks`，不是单个红砖；黏土球不是黏土块。制粉和搅拌的参数100不是固定5秒，实际耗时遵从Create。轴承新增装配保证成功，精密构件原本的制作概率不变。

## 边界与恢复

- [ ] 无热或仅阴燃时，耐火砖配方不完成且不吞原料；补燃料到普通燃烧后能完成。超级加热也能完成，每批仍为4件。
- [ ] 红砖物品、黏土块、未制粉石英不能冒充制砖原料。缺少其中一项不能出砖，补齐后恰好产4件。
- [ ] 搅拌中断热或断动力，再恢复；原料、正在加工材料或已完成输出可以留在原生设备内，但总物料不能丢失或重复产出。
- [ ] 使用自动出料时堵住耐火砖出口，再疏通；输出能恢复，既有物料没有丢失或复制。
- [ ] 轴承尝试错误顺序或错误物品，不推进、不吞错误投入。欠料或断动力后补料/恢复可继续，只得到应有数量。
