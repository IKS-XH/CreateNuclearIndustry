## 本批人工操作与预期

| 检查 | 操作与预期 |
| :--- | :--- |
| 物品、贴图与JEI | 查看铅锭、锡锭、铅板、锡板，物品栏和手持无缺失纹理；两板的颜色和宽薄形状可辨。查看粗矿的熔炉/高炉配方及锭的压片配方/用途。 |
| 两种金属熔炼 | 铅、锡各用1粗矿分别测试熔炉和高炉，加可用燃料，均得到对应1锭。正常20TPS下熔炉约10秒、高炉约5秒。 |
| 两种金属压板 | 有动力的Create压片机下放置物台，各放1对应锭，得到1对应板。压片沿用Create转速规则，不要求固定秒数。 |
| 无动力与恢复 | 压片机无动力时投入1锭应保留；接通动力后正常得到1板，不丢失或重复产出。 |
| 新材料保存 | 把新锭/板放入库存或箱子，保存退出再进入，检查身份与数量保留；仅针对本批新物品。 |

默认配方不直接接收铀、粉碎粗矿、粒或粗矿块；粗矿块沿既有9:1拆解后再熔炼。洗矿、粒换锭、碳粉、制钢及设备制造不在本批，不把缺少这些配方误记为本批回归。
