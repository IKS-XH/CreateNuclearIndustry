## 本批人工操作与预期

| 检查 | 操作与预期 |
| :--- | :--- |
| 矿石、粗矿、粉碎料直熔 | 铅/锡各测试普通矿石、深层矿石、粗矿、粉碎粗矿，每件在熔炉或高炉均得到对应1锭。正常20TPS下熔炉约10秒、高炉约5秒。原矿/粗矿经验0.7，粉碎料按Create为0.1。 |
| Create水洗 | 铅/锡各放1粉碎粗矿，用穿过水的有动力鼓风机加工，固定得到对应9粒，无石料等副产物。无动力等待时保留输入，恢复动力后完成加工，不丢料或重复产出。 |
| 金属粒压合与拆解 | 铅/锡各用9粒合1锭，1锭拆9粒；8粒或混入另一金属不能合成。粒没有1粒熔成1锭的配方。 |
| Create压板 | 有动力压片机下放置物台，各放1铅/锡锭得到对应1板。停转时保料，恢复动力后正常加工。沿用Create转速规则，不要求固定秒数。 |
| 外观与JEI | 查看铅锡锭、粒、板共6种物品，物品栏/手持无缺失纹理；两板方正，粒与锭/粗矿可分辨。用JEI查看直熔、水洗、粒锭合拆及压片配方/用途。 |
| 新材料保存 | 将新锭/粒/板放入库存或箱子，保存退出再进入，身份、数量与贴图保持。 |
