## 当前可接续

用户最新要求优先推进事故与辐射系统，已批准[设计整稿与推荐参数](superpowers/specs/2026-10-16-accident-radiation-design.md)。按辐射基础→事故与清理封存→集中体验/教学分批接续；[第一批计划](superpowers/plans/2026-10-16-radiation-foundation-01.md)只实现使用标记、源/剂量、物流与封存屏蔽、防护服和辐射计。具体进度与人工门见[STATUS](STATUS.md)；不把设计批准当作已实现。

1. 用户已批准按批派发，第一批沿唯一执行者＋一次组合窄审接续；完成后先集中手测，再接第二批局部事故及其清理封装出口。现有融毁事件/判定保持，压力管网和永久区块污染不混入本批。
2. 继续完善现有生存整线：矿物获取→材料与首批冷却剂/设备→燃料制造→发电与回水→枯竭组件封装贮存。[静态核查与集中观察准备](reviews/2026-10-16/main-flow-01/READINESS.md)已列真实衔接及约束，按小规模整线观察连续制造和工质循环，不重开所有已验设备测试。
3. 根据核查结果拆分必要修补；已验配方不自动调数值，新的玩法/成本取舍集中讨论。值班长和新电站协调设备暂不实施，现行管理员应力闭环保留。
4. 屏蔽装配台15C及原反应堆拆除等独立游戏复看按STATUS保留，不把未反馈冒写为通过，也不阻塞只读核查。

以上不自动授权新增功能；已验锅炉16³、管理员/闭环/管网/八类基础思索不再列作待实现或机械重测。历史窄修局部观察按STATUS记录。

## 辅助和远期

模拟器02B单文件与三维辅助工具保留原未验卡，保持离线，不在人工门等待期间自动改跑。三维重建应以实际Minecraft布局为依据，静态验收后再映射动态。

远期仍保留电力转换、多种裂变堆型、航空学移动结构兼容、聚变、反物质及独立化方向；细节参考[整理前策划](archive/2026-10-15/snapshots/docs/project.md)。这些方向没有当前实现授权，首发仍依赖Create并输出SU。

直到首个可发布版本完成，不安排旧存档兼容/迁移研究。新任务须明确需求、依赖、写集、实际技能、必要验证和人工门；采用[治理](project-governance.md)的自动派发规则，不重问已批准项，也不跳过未决取舍。
