## 4. 共用出口

- 身份、资源、翻译、标签与配方依赖完整；生产线能由原版/Create材料达到，废物有明确去向。
- 燃料、热、流体、应力和废料守恒；服务端拥有状态，客户端教学/遥测只显示。
- 自有设备需要真实Create管网、物流/动力的受影响验证；静态模板或纯模型不代替运行集成。
- 按[治理5.1](./project-governance.md#51-按改动范围验证2026-10-02起生效)做增量构建和定向测试，复用未变证据，不机械重复全量。
- 首发前不研究旧存档兼容；当前版本保存加载/生命周期仍按范围验证，不清理用户世界。
- 已实现设备教学逐台播放；版本发布另需生存闭环、表现/性能、全入口教学及交付清单，当前批次验收不自动满足发布门。
