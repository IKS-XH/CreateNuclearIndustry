## 2. 下一阶段顺序

**执行授权（2026-09-29）：** 用户确认资源获取、材料加工、设备制造及 SVG 美术重绘为下一步，并授权自动派发、审核，遇决策或手动测试暂停。本轮按 [启动计划](./superpowers/plans/2026-09-29-resources-production-art-start-plan.md) 已完成四张样稿和最小开工决策包的技术复核，候选尚未接入游戏；当前暂停于 [用户风格与首轮三矿方案评审](./reviews/2026-09-29/README.md)，未批准的矿脉/配方参数不直接实现。

用户已确认 D-01 的先制备后处理顺序，并于 2026-09-29 再次提出优先原材料、设备制备与矿物生成。接续顺序为：

1. 矿物获取、基础加工、工业材料与零件，处理青金石粉候选自身的剩余验收。
2. 首台设备制造、燃料与冷却剂生产，使已有反应堆从原版/Create 材料可达。
3. 换热器、锅炉、汽轮机及热量/流体/应力运行闭环。
4. 乏燃料基础封存；首个完整生存版本必须提供去向。
5. 后续自动化、可变规模、复杂再处理与发布完善。

前两段优先推进。材料与设备按真实依赖拆小卡，避免首台设备依赖自身产物或未建成核机组供热。黑曜石粉随耐热材料和设备制备提前提供，玻璃固化基材在基础封存前提供。扩展 A 是内容分组，其封存尾段不作为扩展 B 的启动前置。

具体矿脉高度、频次、规模、暴露比例，以及配方数量、时间、热级和吞吐尚需按批次冻结；优先级调整不自动批准这些数值。D-01 至 D-03d 已确认事项直接沿用，不重复索取授权。D-03e 未批准候选不构成全项目停止点，只限制依赖它的实现卡。

| 首发扩展 A：生存生产线 | 矿物→材料→设备/燃料/冷却剂，随后补基础封存。所有输入可从原版/Create 获取，标签与自动化入口有效，副产物有去向；数据合同、真实工序与生存人工流程通过 |
| 首发扩展 B：热端与动力 | 热复合冷却剂→锅炉→超临界蒸汽→汽轮机 SU→普通蒸汽→冷凝水。API 探针、热源品质和守恒账本先通过，实际 Create 接入和完整手动回路再验收 |
| P2：自动化与可变规模 | 核心和扩展接口稳定后实现可变反应堆、分段汽轮机、显示链接、比较器、红石安全线路和烈焰人管理员；不反向改变已冻结身份与状态语义 |
| P3：风险与长期闭环 | 辐射、防护、污染、再处理、再生燃料、维护与管道等级；不能成为首发切片前置。首发不注册受污染复合冷却剂、净化器或相关过滤产物 |
| P4：教学、表现与发布评估 | 具体事故验收后完成剩余 Ponder、彩蛋、正式视觉/音效、性能压力测试、许可证及发布准备；彩蛋关闭不影响主线 |

扩展 A 的成本定位为材料投入适中、流程和产线搭建构成主要挑战，小规模起步后通过自动化扩产。每批实现提供首台设备、首批组件、首次充液和扩产的成本/吞吐对照；关系成立不等于数值平衡通过。

扩展 B 必须保持：普通热不能叠加升级为核热品质；只有 `NUCLEAR_SUPERCRITICAL` 产生超临界蒸汽；汽轮机排出同一个普通 `steam`，多主轴不重复结算 SU；冷凝无冷源或出水受阻时不吞蒸汽；缺水、断负载、冷却不足、堵塞和空载有不同反馈。三类设备运行状态稳定后统一冻结反应堆、锅炉和汽轮机的事故、保护、产物及世界修改预算，复用 P1 事件入口。

剩余 Ponder 按[事故后教学计划](./superpowers/plans/2026-09-12-post-accident-ponder-plan.md)实施。全部多方块、设备、管道/端口和主动使用物品须有独立入口，可复用场景；演示搭建、输入输出、自动化及安全行为，中英文齐全，并通过客户端验收。教学只消费客户端表现，不修改服务端状态；它是首发发布门，不阻塞中间功能开发。

## 4. 未决项与已知限制

- **生产参数与设备合同：** 矿物生成、各批加工与副产物参数、首台设备接口和保存/恢复语义，见准备计划第 2、4 节；已批准冷却剂试验配比不等于整线平衡完成。
- **热端 D-04/05/06：** API、热量换算与 SU、普通蒸汽品质语义、锅炉/汽轮机结构和规模仍待明确；不造临时流体或隐藏品质字段消除缺口。
- **GameTest 运行器：** 历史出现原生 tickInternal/fastutil 异常，本轮为断言全过后保存挂起。后续分别记录运行器错误、模组断言失败、通过汇总和退出码，不以修改生产逻辑掩盖问题。
- **工具与候选：** main 模拟器仍是旧倍率基线；02B 的 Node/模块浏览器结果不替代离线验收。青金石粉已注册候选不等于有生存配方。
- **美术与发布：** 当前要求资源引用完整、客户端可识别且无缺失模型；连接纹理、正式模型、动画、粒子和音效在功能闭环后制作。当前许可证为 All Rights Reserved，变更仍由用户决定。

## 5. 共用验收门

1. **身份与资源：** 注册、翻译、模型/纹理、标签、来源及保存合同明确；ID 改动须由项目经理和用户确认。
2. **模拟与守恒：** 核心公式有纯模型测试；燃料、热量、流体、应力及危险废物不得复制或无声删除。
3. **服务端与集成：** 状态、燃耗、损伤及交互由服务端权威校验；客户端只显示。真实 Create 管网、机械臂和轴网须测实际外部路径，不能仅测内部辅助方法。
4. **性能与恢复：** 结构/管网使用缓存，非活动区块不做完整模拟；加载、失效和重载不残留旧能力或遥测，事故世界修改限流。
5. **生存与教学：** 生存扩展须实际走通生产、启动、运行、停机和基础封存；发布前通过全内容 Ponder 人工验收。
6. **交接：** 记录改动、技能、验证命令、失败与通过证据、人工结果、兼容边界及剩余项；项目经理审查后更新状态。

派发、审批、文档维护和 Git 权限统一遵循[治理协议](./project-governance.md)。遇到用户决策或人工门，保存进度并停止相关自动推进；没有另行授权不得自行改跑辅助任务。
