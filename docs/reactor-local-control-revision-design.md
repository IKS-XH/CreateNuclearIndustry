# 反应堆结构、热工与局部控制合同

更新：2026-10-15。保留有效算法和状态所有权，删除旧固定尺寸/旧端口流量/管理员后置等被取代措辞；进度见[STATUS](STATUS.md)，数值见[配置](server-config.md)，自动化见[管理员](reactor-automation.md)。

## 1. 结构与所有权

三边默认5～16的完整长方体，允许跨区块；内部三边各减2，列贯通实际有效高度。边框/角点使用reactor_casing，窗口/功能口按合法位置放置。恰好一个reactor_instrument_port拥有结构缓存和唯一热工/库存/损伤/事故状态。

燃料列为reactor_fuel_rod，上方reactor_refueling_port保存唯一组件ItemStack；仪表快照不另持一份组件。控制棒只注册control_rod_drive，顶驱下方保持空气，棒体是无碰撞客户端模型。冷/热口及自动化口只保存可重建归属，不复制核心状态。

结构变化/扳手请求触发重扫，失效及时撤销绑定和旧事务写权，不清空换料口物品或抢占仍有效的另一座堆。缺失区块不强载；正常运行不每tick全结构扫描。纯冷液的安全拆壳重组按已验规则保实际尺寸/容量，真实核状态不绕过重组拒绝。

## 2. 局部控制

只考虑同一截面的北/南/东/西直接邻接，不计对角。对燃料列f取相邻棒集合C，实际插深d∈[0,1]，0完全拔出、1完全插入；无邻棒时平均插深为0。

```text
meanDepth(f) = C为空时0，否则C中有效实际插深平均
controlledIntensity(f) = (1 - meanDepth(f)) ^ controlResponseExponent
```

卡死棒固定在卡死前实际深度，仍参与平均，但滑块、管理员和SCRAM都不能使其移动。玩家滑块仅预览目标，由服务端验证提交，旧回包不能拉动仍编辑的鼠标/草稿。驱动器不接受红石调棒，红石急停只接仪表口；管理员运行控制权按独立合同交接。

没有任何相邻控制棒的已装可用燃料按无抑制强度运行，可参与燃料反馈；除燃料耗尽，调棒或SCRAM不能使其停热。失效燃料本身不是裂变停止条件：仍有燃料且控制强度非零时按损伤倍率继续结算。

## 3. 相邻燃料反馈、燃耗和产热

四向直接相邻可用燃料形成有界反馈簇，从受棒控制的强度开始、同步读取上一轮相邻结果迭代。反馈门控必须乘该列控制强度，不能在完全插棒后恢复新生裂变热/燃耗；反馈热/燃耗硬上限与全堆产热限幅独立。

每列基础产热/燃耗乘实际有效高度、控制强度、反馈及损伤倍率；每列仍只一个组件。燃耗通过端口ItemStack耐久事务扣除，小数尾量守恒累计，SIMULATE不耗料。全堆新生裂变热汇总限幅后向上取整为整数HU/t，冷却和遥测共用结果；已缓存热不再次取整。

## 4. 冷却与容量

内部空列和控制棒列主体空气格提供冷热共用容量；燃料占用格及非主体空间不重复计容量。每冷/热物理口默认2048mB/t，自身额度供主动/被动/工业事务共用。N冷口/M热口分别提供N/M倍理论吞吐，没有隐藏全堆总封顶；实际受热量、冷液、背压、管网及共享空间共同约束。

默认0.5HU/mB，冷热体积等量。管理员真实维护先扣热，再进入冷却账本。整数mB产生的不到1mB量化尾热守恒累计，不能当真实冷却不足扣完整度、传播或触发融毁；也不能静默删热或改为分数正式库存。容量缩小保库存、拒超额新输入，不制造/删除工质。

## 5. 损伤、传播和维修

真实未覆盖热量超过阈值才降列完整度。损伤端点默认产热2倍/燃耗3倍，须1＜热倍率＜燃耗倍率；非法成对配置按既定校验回退，不静默接受反向/等倍率或非有限数。

失效燃料按当前残余热传播至四邻；控制棒只受传热、不向其他列继续传播，完整度归零卡死在实际深度。钢板维修每次一块、恢复0.25/内部高度，不增加组件燃料或清除已有热。装换料继续经服务端安全判断；快捷替换只对枯竭组件，仍有耐久者拒绝。

## 6. SCRAM与融毁事件

仪表红石高电平且存在控制棒列时建立SCRAM：上升沿保存原目标，全部仍可动棒插到底并锁定控件；下降沿解除并恢复可恢复目标。无棒时报告不可用，不建立假SCRAM或暂停倒计时。

若有效燃料都被相邻完全插入可动棒覆盖，新生裂变热/燃耗必须为零；无覆盖燃料或卡死未完全插棒可能导致停堆不完整。卡死在完全插入且裂变已零的棒不单凭卡死标签报告停堆失败；余热仍需实际冷却。

融毁覆盖比例和倒计时按配置；危险运行/倒计时状态拆组件会推进完成并发布同类事件。服务端仅首次进入COMPLETE发布一次，不因重复tick/加载再发；当前监听端不产生爆炸/辐射/世界破坏，不把事件占位视作事故系统已实现。

## 7. 展示与边界

护目镜/GUI复用服务端缓存：仪表显示真实结构/库存/热工，换料口组件耐久来自本地唯一ItemStack、列状态来自所属仪表；结构不可用明确显示不可用。客户端模型/液位/连接纹理及Ponder不决定热工，不能通过准星观察每tick重扫。

八类基础用法教学已按批验收；原固定5³只是部分验证夹具，不是现结构限制。算法自动证据、实际保存退出与用户观察分别留档；未验范围只在STATUS记录，不在本文件复制候选待测时间线。
